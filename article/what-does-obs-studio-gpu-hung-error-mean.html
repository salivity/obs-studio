What Does OBS Studio GPU Hung Error Mean?

This article provides a quick overview of what the "GPU hung" error signifies in an OBS Studio crash dump, why it happens, and how to resolve it. When this crash occurs, OBS Studio abruptly closes because the graphics processing unit became completely unresponsive during rendering or encoding. Understanding the mechanics behind this error allows you to pinpoint whether the root cause is system resource starvation, driver failure, or hardware instability.

Understanding the "GPU Hung" Error

A "GPU hung" error indicates that OBS Studio submitted a task—such as compositing a frame, applying a filter, or encoding video—to the graphics card, but the GPU failed to complete the task within the operating system's expected time limit.

On Windows, this is closely tied to Timeout Detection and Recovery (TDR). When the GPU freezes or fails to respond within a specific threshold (typically two seconds), Windows forcefully resets the display driver to prevent the entire operating system from locking up. Because the graphics device context is abruptly destroyed and recreated, OBS Studio loses its connection to the GPU pipeline and immediately crashes with the "GPU hung" diagnostic status.

Common Causes

  • GPU Resource Exhaustion: Running an uncapped, resource-intensive game alongside OBS Studio can push the graphics card to 100% utilization. If the game starves the OBS rendering pipeline of necessary GPU cycles, OBS will time out.
  • Corrupt or Outdated GPU Drivers: Graphics drivers can contain bugs or become corrupted over time, leading to memory leaks or internal timeouts under simultaneous gaming and streaming workloads.
  • Aggressive Overclocking or Undervolting: Even if an overclock is stable during standard gameplay, video encoding utilizes separate dedicated silicon blocks on the GPU (such as NVENC or AMF). The combined load of 3D rendering and video encoding can expose hidden hardware instability.
  • Thermal Throttling and Power Fluctuations: If the graphics card reaches thermal limits, it will aggressively downclock, potentially taking too long to execute OBS instructions. Similarly, transient power spikes can cause the GPU to momentarily freeze.
  • Conflicting Background Hardware Acceleration: Browser sources within OBS, third-party overlay software, or Discord hardware acceleration can create resource conflicts that stall the graphics pipeline.

How to Resolve the Error

  1. Run OBS Studio as Administrator: Right-click the OBS Studio shortcut and select "Run as administrator." Windows grants priority GPU scheduling to OBS when elevated, preventing background processes or games from starving the OBS render pipeline.
  2. Cap In-Game Frame Rates: If a game uses 99% to 100% of your GPU, the OBS compositor cannot render frames in time. Limit your game's frame rate to match your monitor's refresh rate or slightly lower, ensuring your GPU operates below peak capacity.
  3. Clean-Install Graphics Drivers: Perform a clean driver installation. Use Display Driver Uninstaller (DDU) in Windows Safe Mode to remove remnants of old drivers, then install the latest stable studio or game-ready drivers from the manufacturer.
  4. Revert Hardware Overclocks: Remove any custom core, memory, or voltage offsets applied through tools like MSI Afterburner. Test OBS at stock clock speeds to verify if hardware instability was causing the hang.
  5. Manage Browser Sources and Third-Party Overlays: If the crash logs point to a specific source, disable hardware acceleration within OBS browser sources or disable external hooks from capture overlays like RivaTuner, Discord, or GeForce Experience.
