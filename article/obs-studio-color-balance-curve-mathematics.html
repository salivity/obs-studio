OBS Studio Color Balance Curve Mathematics

This article breaks down the mathematical curves used to isolate shadows, midtones, and highlights during color grading and color balancing in OBS Studio shader pipelines. It details the luminance calculation, the cubic Hermite functions used to segment tonal ranges, and how these curves prevent banding while blending color adjustments across an image.

Luminance Calculation

Before applying tonal isolation curves, the filter calculates the perceived luminance (\(Y\)) of each pixel from its linear or gamma-corrected RGB values. In standard OBS Studio shaders and standard color pipelines conforming to ITU-R BT.709, luminance is derived using the standard weighted sum:

\[Y = 0.2126R + 0.7152G + 0.0722B\]

This scalar value represents the brightness of the pixel on a scale from \(0.0\) (pure black) to \(1.0\) (pure white) and serves as the input parameter for the isolation curves.

The Isolation Curve: Smoothstep (Cubic Hermite Spline)

To separate shadows and highlights without creating harsh transitions or color banding, real-time shading pipelines in OBS Studio rely on the cubic Hermite spline, natively implemented in HLSL as the smoothstep function.

The standard smoothstep function transitions smoothly between two thresholds, \(e_0\) and \(e_1\), using the polynomial:

\[f(t) = 3t^2 - 2t^3 \quad \text{where} \quad t = \text{clamp}\left(\frac{Y - e_0}{e_1 - e_0}, 0.0, 1.0\right)\]

This curve produces zero first derivatives at both boundaries (\(t = 0\) and \(t = 1\)), ensuring continuous, smooth slope transitions between affected and unaffected tonal zones.

Shadow Isolation Curve

Shadow weighting isolates low-luminance pixels. The weight curve starts at \(1.0\) at pure black and smoothly descends to \(0.0\) at a defined shadow threshold (\(T_s\)):

\[W_{\text{shadow}}(Y) = 1.0 - \text{smoothstep}(0.0, T_s, Y)\]

Alternatively, when parameterized with a midpoint soft-knee, the curve drops monotonically as luminance rises toward the midtones.

Highlight Isolation Curve

Highlight weighting isolates high-luminance pixels. The weight curve remains at \(0.0\) until reaching a highlight threshold (\(T_h\)), then ascends smoothly to \(1.0\) at pure white:

\[W_{\text{highlight}}(Y) = \text{smoothstep}(T_h, 1.0, Y)\]

Midtone Isolation Curve

Midtones are defined mathematically by the residual tonal space. The shader calculates midtone weighting either by subtracting the shadow and highlight weights from unity or by using a symmetric bell-shaped polynomial:

\[W_{\text{mid tone}}(Y) = 1.0 - W_{\text{shadow}}(Y) - W_{\text{highlight}}(Y)\]

When implemented as an independent bell curve, a parabolic or raised-cosine function is often utilized:

\[W_{\text{mid tone}}(Y) = 4Y(1.0 - Y)\]

Pixel Blending and Output

The final color adjustment is computed by multiplying the user's color offset parameters (\(C_{\text{shadow}}\), \(C_{\text{midtone}}\), and \(C_{\text{highlight}}\)) by their respective weights and adding them to the base image:

\[\text{Color}_{\text{out}} = \text{Color}_{\text{in}} + (W_{\text{shadow}} \cdot C_{\text{shadow}}) + (W_{\text{mid tone}} \cdot C_{\text{midtone}}) + (W_{\text{highlight}} \cdot C_{\text{highlight}})\]

By relying on smooth cubic Hermite interpolation, the filter ensures that tonal boundaries blend naturally across dynamic live video feeds without introducing visual artifacts.
