Inspect OBS Core Distribution in Performance Monitor

Windows Performance Monitor provides deep insight into how OBS Studio distributes its execution threads across your system's logical CPU cores. Monitoring these metrics allows you to identify thread contention, detect whether threads are stuck on inefficient efficiency cores (E-cores), and evaluate encoder load distribution during live captures or streams.

Step 1: Prepare OBS Studio for Monitoring

To generate meaningful telemetry, OBS Studio must actively run a workload:

  1. Launch OBS Studio.
  2. Start your typical workflow, such as active streaming, local recording, or enabling the Virtual Camera with your usual scenes and plugins active.
  3. Keep OBS running in the background so its threads register actively in the system counters.

Step 2: Open and Configure Performance Monitor

  1. Press Win + R, type perfmon.msc, and press Enter to open Performance Monitor.
  2. In the left navigation pane, expand Monitoring Tools and select Performance Monitor.
  3. Clear the default counter by selecting % Processor Time in the bottom pane and pressing the Delete key.
  4. Click the green Add (+) icon on the toolbar to open the Add Counters dialog.

Step 3: Add OBS Process and Thread Counters

To track core distribution and per-thread CPU utilization, add the relevant thread counters:

  1. In the counter list, scroll to and expand the Thread object.
  2. Select the % Processor Time counter.
  3. Under Instances of selected object, scroll to find instances labeled obs64 (or obs32 if on a legacy setup). You will see instances named obs64/0, obs64/1, obs64/2, representing individual worker threads.
  4. Select all obs64 instances and click Add >>.

Step 4: Add Per-Core Processor Information

To correlate which physical or logical cores are absorbing the workload:

  1. In the same Add Counters dialog, scroll up to Processor Information.
  2. Select the % Processor Utility or % Processor Time counter.
  3. Under Instances of selected object, choose <All instances> to monitor every logical core independently.
  4. Click Add >>, then click OK to apply the configuration.

Step 5: Analyze Thread Activity and Core Affinity

  1. Switch the view format for easier reading by pressing Ctrl + G or clicking the Change graph type button on the toolbar, then select Report or Histogram Bar.
  2. Identify Heavy Threads: Locate which obs64 thread instances consume the highest percentages of processor time. The highest-load threads typically represent the rendering loop and the video encoder.
  3. Check Core Distribution: Compare the active obs64 thread utilization rates with the active CPU core instances under Processor Information. If one or two specific CPU cores spike in lockstep with the primary OBS threads, those threads are pinned or scheduled to those particular logical cores.
  4. Detect Contention or Inefficient Scheduling: On hybrid CPUs with Performance and Efficient cores (such as Intel 12th Gen and newer), verify whether peak OBS thread activity aligns with the index numbers of your Performance cores rather than trailing off onto low-clocked Efficiency cores.
