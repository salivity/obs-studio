How to Route Independent Audio Mixes in OBS Studio

OBS Studio manages independent audio feeds for broadcast streams, floor monitors, and talent earpieces by combining multi-track audio routing, the native audio monitoring engine, and specialized audio routing plugins or hardware outputs. While native OBS offers a primary mix for the stream and a secondary mix for monitoring, achieving three or more truly distinct mixes requires assigning specific audio tracks to dedicated hardware outputs or using plugins to tap into individual channel buses.

Native Track Routing vs. Audio Monitoring

OBS Studio natively divides audio into six internal tracks and a dedicated Monitoring Device:

  • Broadcast Mix (Track 1): In Settings > Output, the live stream encoder is mapped to a specific track (typically Track 1). In Edit > Advanced Audio Properties, any source checked under Track 1 will be heard by the internet audience.
  • The Native Monitoring Bus: In Settings > Audio, you designate an "Audio Monitoring Device." This sends sound to a selected hardware output (such as a physical headphone jack, an auxiliary output, or a virtual cable). In Advanced Audio Properties, setting a source to "Monitor and Output" sends it to both the stream and this monitoring device, while "Monitor Only (mute output)" routes it strictly to the monitor output.

Because native OBS provides only one global monitoring device, it can natively split audio into two distinct destinations (e.g., Stream and Floor Monitors). Creating a third independent mix for talent earpieces requires additional routing methods.

Creating Three Distinct Mixes

To deliver customized audio to the stream, floor monitors, and talent earpieces simultaneously, standard production workflows employ the following techniques:

1. The Broadcast Mix

Configure your live stream to use Track 1. In Advanced Audio Properties, check Track 1 for every audio element the remote audience should hear, such as main microphones, game audio, media sources, and alert sounds.

2. Floor Monitors (Native Monitoring Bus)

Route the native monitoring bus to the floor monitor speakers:

  • Go to Settings > Audio and set the Audio Monitoring Device to the physical audio output connected to your floor monitors.
  • In Advanced Audio Properties, set audience-facing mics and media sources to Monitor and Output.
  • Ensure that microphones near the floor monitors are set to Monitor Off to prevent feedback loops, keeping their signal exclusive to the broadcast.

3. Talent Earpieces (IFB Routing via Plugin or Virtual Cable)

Talent earpieces typically require an IFB (Interruptible Foldback) feed containing production cues, intercoms, and program audio, while excluding the talent's own voice to avoid distracting latency. Because the primary monitoring bus is already used by the floor monitors, use one of the following methods for the earpieces:

  • Audio Monitor Filter Plugin: Install the popular third-party "Audio Monitor" filter. This filter allows you to attach an independent audio output directly to any source or scene. Add this filter to intercoms, program audio, and director mics, assigning the filter's target device directly to the talent's wireless transmitter or headphone interface.
  • Multi-Track ASIO / Auxiliary Outputs: When using an audio interface with multiple physical outputs, route individual OBS tracks directly to your hardware. By sending different track combinations to physical Outputs 1-2 (Floor) and Outputs 3-4 (Talent), you maintain independent volume and source balances.
  • Virtual Audio Cables: Map specific sources or scenes to a virtual cable (such as VB-Cable), which in turn feeds external routing software or an auxiliary headphone mix on your sound card.

Fine-Tuning Balances in Advanced Audio Properties

Once the physical and virtual routes are established, finalize the setup in Advanced Audio Properties:

  • Volume Sliders: Set the relative levels of each source. Filters applied directly to a source (like gain, compression, or the Audio Monitor filter) affect downstream routing accordingly.
  • Sync Offset: If wireless earpieces or remote video streams introduce latency, adjust the sync offset per device to ensure floor monitors and in-ear feeds remain phase-coherent with the live visual performance.
