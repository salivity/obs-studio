OBS Studio HEVC Main10 Setup for 10-Bit Archival

Configuring OBS Studio for a true 10-bit broadcast archival workflow requires aligning the rendering pipeline, color management, and encoder properties with the HEVC Main10 specification. By transitioning internal rendering from standard 8-bit NV12 to a native 10-bit format like P010, selecting hardware or software encoders capable of HEVC Main10, and defining strict rate control parameters, broadcast professionals can record high-fidelity footage without color banding or precision loss.

1. Configure the 10-Bit Color Pipeline

Before the encoder can output a 10-bit file, OBS Studio must be configured to process color at a 10-bit depth. By default, OBS operates in an 8-bit color space.

  1. Open Settings and navigate to the Advanced tab.
  2. Locate the Video section.
  3. Change Color Format to P010 (10-bit 4:2:0 format natively supported by HEVC Main10) or I010 if supported by your capture hardware.
  4. Set the Color Space:
    • For standard-dynamic-range (SDR) 10-bit archival, select Rec. 709.
    • For high-dynamic-range (HDR) archival, select Rec. 2100 (PQ) or Rec. 2100 (HLG).
  5. Set Color Range to Limited for standard broadcast-compliant workflows, or Full if your downstream editing pipeline specifically requires full-range mastering.

2. Output and Container Configuration

Archival workflows require fault-tolerant containers to prevent file corruption in case of unexpected power loss or system crashes.

  1. Navigate to Settings > Output.
  2. Change the Output Mode dropdown at the top to Advanced.
  3. Select the Recording tab.
  4. Set Type to Standard.
  5. Set Recording Format to Matroska Video (.mkv) or Fragmented MP4 (.mp4). The standard non-fragmented MP4 container is not recommended for production archival because an incomplete write can corrupt the entire file.

3. Encoder Selection and Main10 Profile Enforcement

To write true 10-bit data, the encoder must be set to the HEVC (H.265) codec and locked to the Main10 profile.

  • NVIDIA NVENC HEVC: In the Recording tab, set Video Encoder to NVIDIA NVENC HEVC. When P010 is set in the Advanced settings, NVENC will automatically switch to the Main10 profile. Ensure the Profile option is explicitly set to main10 rather than main.
  • AMD HW HEVC (AMF) / Intel Quick Sync HEVC: Select the respective HEVC encoder. Under profile settings, explicitly choose Main10.
  • Software (x265): If using CPU-based archival, choose x265. Under custom parameters, include profile=main10 to enforce 10-bit output.

4. Rate Control for Broadcast Mastering

Archival workflows prioritize visual fidelity over bandwidth constraints. Constant Bitrate (CBR) should be avoided for local archiving.

  1. Set Rate Control to CQP (Constant Quantization Parameter) for hardware encoders, or CRF (Constant Rate Factor) for software encoders.
  2. Set the CQ/CRF target:
    • CQ 14 to 18: Ideal for broadcast masters and intermediate archives, offering visually lossless preservation.
    • CQ 19 to 22: High quality with reduced storage footprints.
  3. Set Keyframe Interval to 1s or 2s to facilitate responsive scrubbing and timeline navigation during post-production.
  4. Set Tuning to High Quality and Multipass Mode to Two Passes (Quarter Resolution) or Two Passes (Full Resolution) depending on GPU headroom.

5. Verification

After recording a test sample, verify that the pipeline is functioning at true 10-bit depth using an analysis tool like MediaInfo. Inspect the generated file to ensure the following parameters are present:

  • Format: HEVC
  • Format profile: Main 10@L...
  • Bit depth: 10 bits
  • Color space: YUV
  • Chroma subsampling: 4:2:0
