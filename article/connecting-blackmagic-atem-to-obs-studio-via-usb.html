Connecting Blackmagic ATEM to OBS Studio via USB

Hardware vision mixers like the Blackmagic ATEM series seamlessly bridge the gap between broadcast-grade production and digital streaming software through standard USB webcam emulation. This article explains the technical mechanics behind how OBS Studio detects and processes video from ATEM hardware over USB, outlines the step-by-step setup required to integrate the two systems, and highlights essential best practices for latency and audio synchronization.

How USB Webcam Emulation Works

Modern hardware switchers, notably the Blackmagic ATEM Mini family, include a USB-C output port programmed to conform to UVC (USB Video Class) and UAC (USB Audio Class) protocols. Instead of requiring proprietary capture drivers, the operating system recognizes the ATEM mixer as a standard plug-and-play webcam.

When the switcher mixes HDMI sources, it scales and encodes the program output into an uncompressed or lightly compressed video stream, delivering it directly to the host computer across the USB bus. OBS Studio reads this incoming feed identically to any consumer USB camera, entirely bypassing the need for dedicated PCIe or external HDMI capture cards.

Step-by-Step Integration in OBS Studio

  1. Physical Connection: Connect a USB-C to USB-A (or USB-C to USB-C) cable from the ATEM's "Webcam Out" port to an available USB 3.0 or higher port on the computer.
  2. Add a Video Source: Open OBS Studio, navigate to the Sources dock, click the + icon, and select Video Capture Device.
  3. Select Hardware: Name the source (e.g., "ATEM Program Out"), and from the Device drop-down menu, select Blackmagic Design (or the specific model name).
  4. Configure Resolution and Frame Rate: Set Resolution/FPS Type to Custom. Match the resolution (typically 1920x1080) and frame rate (such as 59.94, 60, or 29.97 fps) to the internal processing settings configured on the ATEM switcher.
  5. Route Mixer Audio: Scroll down in the device properties, check Use custom audio device, and select the ATEM mixer as the audio input to maintain unified video and audio capture.

Hybrid Production Workflow Benefits

Using an ATEM mixer in conjunction with OBS Studio creates a hybrid architecture that splits computational workloads:

  • Hardware Offloading: Camera switching, HDMI signal conversion, hardware chroma keying, and multi-view monitoring are handled entirely by the ATEM's internal FPGA processor, drastically reducing host CPU and GPU usage.
  • Software Versatility: OBS Studio acts as the master distribution hub, handling dynamic graphic overlays, browser sources, scene transitions, localized stream encoding, multi-platform streaming, and recording.

Optimization and Troubleshooting

  • Matching Frame Rates: Ensure the ATEM internal frame rate set in the ATEM Software Control matches the canvas and output settings in OBS Studio. Mismatched frame rates force software interpolation, introducing frame drops or jitter.
  • Audio-Video Delay: Because hardware switchers take a small number of frames to process incoming video sources, audio sent directly to the PC via another interface might fall out of sync. To resolve this, route primary microphones into the ATEM's analog inputs so audio is processed and multiplexed over the USB feed alongside the video, or apply an Audio Delay (Sync Offset) inside OBS Studio's Advanced Audio Properties.
