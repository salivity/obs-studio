OBS Studio Dynamic File Naming Guide

OBS Studio allows content creators to automate recording organization using dynamic file naming conventions based on format specifiers. By utilizing standardized time and date variables, OBS automatically generates unique filenames and subfolders for each recording session, preventing accidental file overwrites and eliminating the need to rename media manually after each stream or capture.

Accessing Filename Formatting Settings

To configure dynamic file names in OBS Studio:

  1. Open OBS Studio.
  2. Navigate to Settings in the bottom right corner or via File > Settings.
  3. Select the Advanced tab from the left navigation panel.
  4. Locate the Recording section.
  5. Edit the input field labeled Filename Formatting.

By default, OBS uses %CCYY-%MM-%DD %hh-%mm-%ss or %Y-%m-%d %H-%M-%S depending on the installation version.

Core Date and Time Format Specifiers

OBS Studio relies on standard C-style strftime format specifiers. These variables begin with a percent sign (%) followed by a character indicating the specific data point:

Year Variables

  • %Y: Four-digit year (e.g., 2024)
  • %y: Two-digit year (e.g., 24)

Month Variables

  • %m: Month as a zero-padded number (e.g., 01 to 12)
  • %b: Abbreviated month name (e.g., Jan, Feb, Mar)
  • %B: Full month name (e.g., January, February)

Day Variables

  • %d: Day of the month as a zero-padded number (e.g., 01 to 31)
  • %e: Day of the month without leading zeros (e.g., 1 to 31)
  • %a: Abbreviated weekday name (e.g., Mon, Tue)
  • %A: Full weekday name (e.g., Monday, Tuesday)

Time Variables

  • %H: Hour in 24-hour format (e.g., 00 to 23)
  • %I: Hour in 12-hour format (e.g., 01 to 12)
  • %p: AM or PM designation
  • %M: Minute (e.g., 00 to 59)
  • %S: Second (e.g., 00 to 59)

Automatic Folder Creation

OBS Studio can generate directory structures automatically by including forward slashes (/) or backslashes (\) inside the Filename Formatting field. When OBS detects a directory separator, it creates the corresponding folder path inside the primary recording directory specified in the Output settings.

  • Format: %Y/%m/%d/%Y-%m-%d_%H-%M-%S
  • Resulting Path: 2024/05/18/2024-05-18_14-30-00.mkv

This structure groups recordings into year, month, and day folders automatically.

Practical Naming Templates

Standard Timestamp

  • Template: %Y-%m-%d_%H-%M-%S
  • Output: 2024-10-15_18-45-12.mp4
  • Use Case: Clear chronological sorting in a flat folder.

Project-Specific Labeling

  • Template: Gameplay_%Y%m%d_%H%M
  • Output: Gameplay_20241015_1845.mp4
  • Use Case: Separating specific content types while retaining compact date tracking.

Monthly Folder Archive

  • Template: %Y-%m/%B_%d_%Y_%I-%M-%S_%p
  • Output: 2024-10/October_15_2024_06-45-12_PM.mp4
  • Use Case: High-volume recording workflows that require nested month-by-month archival.
