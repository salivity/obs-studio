Set Up an OBS Confidence Monitor with Audio Meters

Setting up an independent confidence monitor in OBS Studio allows talent and production crews to view live Program output, upcoming Preview shots, and real-time audio VU meters simultaneously on a dedicated auxiliary display. This setup can be accomplished natively using OBS Studio’s built-in Multiview engine or by arranging custom windowed projectors alongside undocked audio panels. The following guide covers the most reliable methods to configure an independent, informative confidence feed for your production environment.

Method 1: The Native Multiview Projector

The fastest and most resource-efficient way to provide an all-in-one confidence feed is utilizing the native Multiview feature in OBS Studio. It consolidates Preview, Program, individual scenes, and active audio VU meters into a single layout.

1. Enable Audio Meters in Multiview

  1. Open OBS Studio and navigate to File > Settings (or OBS Studio > Preferences on macOS).
  2. Select the General tab from the left sidebar.
  3. Scroll down to the Multiview section.
  4. Check the box labeled Draw audio meters (this ensures horizontal VU meters display beneath the Preview and Program panels).
  5. Optional: Adjust the Multiview Layout dropdown to adjust scene arrangement based on your talent's preference (e.g., 8 scenes, 16 scenes, or single-tier layouts).
  6. Click Apply and OK.

2. Output Multiview to an Independent Display

  1. Ensure your external confidence display is connected and extended (not mirrored) in your operating system's display settings.
  2. In OBS Studio, click on the View menu at the top.
  3. Hover over Multiview (Fullscreen).
  4. Select the monitor designated for talent or backstage confidence monitoring.

The monitor will instantly display Preview on the left, Program on the right, audio level bars under both feeds, and selectable scene thumbnails below.

Method 2: Custom Layout Using Docks and Windowed Projectors

If the Multiview layout displays too much visual clutter and the talent only needs Preview, Program, and large audio meters, you can build a custom layout across the second monitor using undocked UI elements.

1. Prepare Studio Mode

  1. Click the Studio Mode button located in the lower-right control panel.
  2. This establishes the two-panel workflow where Preview sits on the left and Program sits on the right.

2. Undock the Audio Mixer

  1. Ensure docks are movable by going to Docks in the top menu bar and unchecking Lock Docks.
  2. Click and drag the title tab of the Audio Mixer to tear it away from the main OBS window.
  3. Drag the floating Audio Mixer window over to the confidence monitor.
  4. Resize the window vertically or horizontally so the green/yellow/red decibel meters are prominent and easily visible from a distance.

3. Open Windowed Projectors

  1. Right-click on the Preview canvas inside OBS Studio.
  2. Select Windowed Projector (Preview).
  3. Drag the created projector window to the confidence display and scale it to fit alongside the mixer.
  4. Right-click on the Program canvas inside OBS Studio.
  5. Select Windowed Projector (Program).
  6. Drag the Program window onto the confidence monitor next to the Preview window.

Method 3: Dedicated "Confidence" Scene with Plugin Clones

For fixed studio installations requiring a singular, customized video signal (such as an HDMI send through a dedicated graphics card port or hardware video distributor):

  1. Install the open-source Source Clone plugin for OBS Studio.
  2. Create a new scene named Confidence Monitor.
  3. Add a Source Clone layer targeting your active Program output and position it on the canvas.
  4. Add another Source Clone layer targeting your Preview feed.
  5. Add custom overlay elements, such as third-party audio dock captures or browser-based streaming timers/clocks.
  6. Right-click the Confidence Monitor scene in the Scenes list, choose Fullscreen Projector (Scene), and assign it to the confidence display output.
