OBS Studio Multi-Channel AAC MP4 Audio Metadata

When OBS Studio records multi-channel AAC audio into an MP4 container, it relies on FFmpeg’s libavformat library to generate standard ISO Base Media File Format (ISOBMFF) atoms and MPEG-4 audio descriptors. This article explains the exact container boxes, descriptor flags, and bitstream markers OBS Studio writes to signal channel layouts—such as stereo, 5.1, or 7.1 surround sound—inside an MP4 file.

The MP4 Audio Sample Entry (mp4a)

At the container level, audio track configurations are defined inside the moov atom under the sample table hierarchy (moov > trak > mdia > minf > stbl > stsd).

For AAC audio, OBS Studio creates an mp4a audio sample entry containing the following primary metadata fields:

  • Channel Count: A 16-bit unsigned integer representing the total number of audio channels (e.g., 2 for stereo, 6 for 5.1 surround, or 8 for 7.1 surround).
  • Sample Size: A 16-bit integer default set to 16 bits.
  • Sample Rate: A 32-bit fixed-point integer representing the frequency (e.g., 44100 or 48000 Hz) shifted into 16.16 format.

The Elementary Stream Descriptor (esds)

Inside the mp4a box, OBS writes an esds atom, which carries the MPEG-4 Elementary Stream Descriptor. This atom encapsulates the DecoderConfigDescriptor and the critical AudioSpecificConfig (ASC), which decoders use to determine layout and profile information:

  • Object Type Indication: Set inside the DecoderConfigDescriptor to 0x40, designating standard MPEG-4 Audio (Audio ISO/IEC 14496-3).
  • Stream Type: Set to 0x05 (Audio Stream).
  • Audio Object Type (AOT): Encoded in the AudioSpecificConfig bitstream. OBS typically encodes using AAC-LC (Low Complexity), writing a value of 2.
  • Channel Configuration: A 4-bit field in the AudioSpecificConfig defining the speaker layout:
    • 1: Mono (1 channel: center)
    • 2: Stereo (2 channels: left, right)
    • 3: 3.0 (3 channels: center, left, right)
    • 4: 4.0 (4 channels: center, left, right, surround rear)
    • 5: 5.0 (5 channels: center, front left, front right, surround left, surround right)
    • 6: 5.1 Surround (6 channels: center, front left, front right, surround left, surround right, LFE)
    • 7: 7.1 Surround (8 channels: center, front left, front right, side left, side right, rear left, rear right, LFE)

If a non-standard speaker layout is used, the channelConfiguration is set to 0, and an explicit program_config_element() (PCE) is written directly into the bitstream to map individual speaker positions.

Track and Media Headers

OBS Studio also populates basic structural metadata across corresponding audio headers:

  • tkhd (Track Header): Sets track volume (typically 0x0100 for full volume / 1.0) and assigns a unique track_ID for each audio track enabled in OBS output settings.
  • mdhd (Media Header): Contains duration values, creation/modification timestamps, and a packed 15-bit ISO-639-2/T language code (defaulting to und for undefined unless otherwise set).

Multi-Track Output Structure

When configured to record multiple separate audio tracks simultaneously, OBS Studio does not multiplex channels into a single unified stream. Instead, it generates separate trak boxes for each selected track. Each track contains its own independent mp4a sample entry and esds descriptor matching the respective track's channel configuration.
