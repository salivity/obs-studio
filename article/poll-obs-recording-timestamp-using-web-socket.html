Poll OBS Recording Timestamp Using WebSocket

This guide explains how an external script can connect to OBS Studio and continuously poll the exact timestamp of an active recording using the OBS WebSocket protocol. By leveraging the modern OBS WebSocket v5 API, an external script can establish a persistent connection, authenticate, and request real-time recording metrics—including elapsed time in milliseconds and formatted timecodes—to keep external tools synchronized with your stream or recording session.

Protocol Overview: OBS WebSocket v5

OBS Studio version 28 and later includes built-in support for the OBS WebSocket v5 protocol. To retrieve recording metrics, an external client sends a request of type GetRecordStatus.

When an active recording is in progress, the response payload provides several key metrics:

  • outputActive (boolean): Indicates whether recording is currently running.
  • outputPaused (boolean): Indicates whether the recording is paused.
  • outputTimecode (string): The current recording duration formatted as HH:MM:SS.mmm.
  • outputDuration (integer): The elapsed recording time in milliseconds.
  • outputBytes (integer): The total bytes written so far.

Setting Up OBS Studio

  1. Open OBS Studio.
  2. Navigate to Tools > WebSocket Server Settings.
  3. Check Enable WebSocket server.
  4. Note the Server Port (default is 4455) and the Server Password (if authentication is enabled).

Polling Implementation (Python Example)

The following example uses the modern obsws-python library to connect to OBS, poll the recording status every second, and print the exact timestamp.

To install the required library:

pip install obsws-python

Script Implementation

import time
import obsws_python as obs

# Configuration
OBS_HOST = "localhost"
OBS_PORT = 4455
OBS_PASSWORD = "your_obs_password"
POLL_INTERVAL = 1.0  # Polling rate in seconds

def poll_recording_timestamp():
    # Initialize the RequestClient
    client = obs.ReqClient(host=OBS_HOST, port=OBS_PORT, password=OBS_PASSWORD)
    print("Connected to OBS Studio.")

    try:
        while True:
            # Send GetRecordStatus request
            status = client.get_record_status()

            if status.output_active:
                timecode = status.output_timecode
                duration_ms = status.output_duration
                is_paused = status.output_paused
                
                state = "PAUSED" if is_paused else "RECORDING"
                print(f"[{state}] Timecode: {timecode} | Duration (ms): {duration_ms}")
            else:
                print("Recording is currently inactive.")

            time.sleep(POLL_INTERVAL)

    except KeyboardInterrupt:
        print("\nPolling stopped by user.")
    except Exception as e:
        print(f"An error occurred: {e}")

if __name__ == "__main__":
    poll_recording_timestamp()

Raw JSON-RPC Request Format

If you are writing a custom client without high-level wrapper libraries, your script must send an OpCode 6 (Request) message over the WebSocket connection once the initial handshake and authentication (OpCode 1) are complete:

{
  "op": 6,
  "d": {
    "requestType": "GetRecordStatus",
    "requestId": "poll-record-status-001"
  }
}

The OBS server returns an OpCode 7 (RequestResponse) message:

{
  "op": 7,
  "d": {
    "requestType": "GetRecordStatus",
    "requestId": "poll-record-status-001",
    "requestStatus": {
      "result": true,
      "code": 100
    },
    "responseData": {
      "outputActive": true,
      "outputPaused": false,
      "outputTimecode": "00:04:15.833",
      "outputDuration": 255833,
      "outputBytes": 83886080
    }
  }
}

Parse responseData.outputDuration for numeric calculations or responseData.outputTimecode for display purposes.
