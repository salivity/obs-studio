How to Output Anamorphic Video in OBS Studio

OBS Studio does not natively support non-square pixel aspect ratios (PAR), but you can successfully configure it for specialized anamorphic projection by utilizing custom canvas resolutions and manual source transformations. While OBS internally renders and outputs frames strictly with a 1:1 square pixel aspect ratio, you can pre-squeeze or pre-stretch content within the software so that an external projector, hardware scaler, or optical anamorphic lens can expand the image to the correct proportions.

Understanding OBS Pixel Aspect Ratio Limitations

OBS Studio relies entirely on square pixels. It does not provide metadata flags to tag video streams with non-square pixel aspect ratios (such as 1.33:1, 1.5:1, or 2.0:1 PAR). Consequently, any anamorphic workflow in OBS must be achieved by manipulating the canvas resolution geometry (storage aspect ratio) rather than relying on automated pixel-stretching metadata.

Step-by-Step Configuration for Anamorphic Projection

1. Configure the Canvas Resolution

To feed an anamorphic projection system, your OBS canvas must match the native input resolution expected by your projector or display processor.

  1. Navigate to Settings > Video.
  2. Set Base (Canvas) Resolution to your projector's native display resolution (for example, 1920x1080 for standard 1080p projectors, or 3840x2160 for 4K units).
  3. Set Output (Scaled) Resolution to the exact same value to avoid unnecessary secondary scaling.
  4. Set the framerate to match your projector's native refresh rate.

2. Apply the Anamorphic Squeeze to Content

If you are displaying ultrawide content (such as 2.39:1 CinemaScope) through an anamorphic lens that horizontally stretches the image by a factor of 1.33x or 2.0x, you must compress the source horizontally across the canvas:

  1. Add your media source or capture device to the Sources dock.
  2. Right-click the source and select Transform > Edit Transform (or press Ctrl + E).
  3. Set the Bounding Box Type to Scale to inner bounds or manually adjust the dimensions:
    • To fit a 2.39:1 source into a 16:9 (1.78:1) frame for a 1.33x anamorphic lens, adjust the source width and height so that the image fills the entire 16:9 area without letterboxing. The content will look horizontally squished on your preview monitor.
  4. Ensure Positional Alignment is centered.

3. Outputting to the Specialized Display

Once the preview shows the properly squeezed image:

  1. Right-click anywhere in the OBS preview window.
  2. Navigate to Fullscreen Projector (Program).
  3. Select the target specialized projector or output display connected to your graphics card.

The projector receives the pre-distorted frame, and the attached optical anamorphic lens or internal projection display mode expands the pixels horizontally, restoring the geometry to the correct viewing aspect ratio on screen.
