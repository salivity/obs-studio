How to Auto Delete OBS Recordings Older Than 30 Days

OBS Studio does not include a native feature to purge old video files, which can cause local storage drives to fill up quickly. You can automate the deletion of recordings older than thirty days by writing a lightweight external script and scheduling it to run automatically via your operating system's task scheduler. This guide covers how to identify your OBS recording directory, write the cleanup script for Windows or Linux/macOS, and automate the process.

Step 1: Identify Your OBS Recording Directory

Before creating a script, you must determine where OBS Studio saves your video files.

  1. Open OBS Studio.
  2. Navigate to Settings in the bottom-right corner (or go to File > Settings).
  3. Select the Output tab from the left sidebar.
  4. Locate the Recording Path under the Recording section.
  5. Note this folder path, as it will be used directly in your cleanup script.

Step 2: Create the Deletion Script

Choose the appropriate script based on your operating system.

Windows (PowerShell)

  1. Open Notepad or a text editor.
  2. Paste the following script:
$TargetFolder = "C:\Users\YourUsername\Videos"
$Days = 30
$Extension = "*.mp4" # Change or remove to match your recording format (e.g., *.mkv)

Get-ChildItem -Path $TargetFolder -Filter $Extension -Recurse -File | 
Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-$Days) } | 
Remove-Item -Force
  1. Replace C:\Users\YourUsername\Videos with your actual OBS recording path.
  2. Save the file with a .ps1 extension (for example, clean_obs_recordings.ps1).

Linux and macOS (Bash)

  1. Open a terminal and create a shell script:
nano clean_obs.sh
  1. Add the following command:
#!/bin/bash
TARGET_DIR="/path/to/your/recordings"
find "$TARGET_DIR" -type f \( -name "*.mp4" -o -name "*.mkv" \) -mtime +30 -exec rm -f {} \;
  1. Replace /path/to/your/recordings with your actual directory path.
  2. Save and exit, then make the script executable:
chmod +x clean_obs.sh

Step 3: Automate the Script

To ensure recordings are removed without manual intervention, configure your system to run the script on a recurring schedule.

Setting Up Windows Task Scheduler

  1. Press Win + R, type taskschd.msc, and press Enter.
  2. Click Create Basic Task in the right-hand panel.
  3. Name the task (e.g., OBS Auto-Cleanup) and click Next.
  4. Set the trigger to Daily and choose a preferred time.
  5. Under Action, select Start a program and click Next.
  6. In the Program/script field, type: 
    powershell.exe
  7. In the Add arguments field, enter: 
    -ExecutionPolicy Bypass -File "C:\Path\To\clean_obs_recordings.ps1"
    (Ensure you use the full path to your saved script).
  8. Click Finish.

Setting Up Linux/macOS Cron

  1. Open the cron table by running: 
    crontab -e
  2. Add a line to execute the script daily (for example, every day at midnight): 
    0 0 * * * /path/to/clean_obs.sh >/dev/null 2>&1
  3. Save and close the editor.
