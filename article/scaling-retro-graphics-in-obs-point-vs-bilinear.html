Scaling Retro Graphics in OBS: Point vs Bilinear

When capturing retro video games in OBS Studio, choosing the correct scale filtering method determines whether your output displays crisp, authentic pixels or a smeared, blurry image. Nearest-neighbor (labeled as "Point" in OBS) duplicates existing pixels to preserve sharp edges and distinct color boundaries, while bilinear interpolation averages adjacent pixels to smooth transitions. Understanding how these two algorithms handle low-resolution raster graphics ensures your stream or recording maintains the intended visual aesthetic of classic games.

How Nearest-Neighbor (Point) Scaling Works

Nearest-neighbor interpolation, designated as Point filtering in OBS Studio, is the simplest scaling algorithm. When an image is enlarged, the algorithm maps each new pixel coordinate to the closest matching pixel in the original low-resolution source and directly copies its color value without modification.

  • Aesthetic Result: It produces hard, well-defined rectangular edges. Individual pixels remain clearly visible and maintain their original palette purity without introducing new intermediate colors.
  • Best Use Case: It is the standard choice for retro consoles (NES, SNES, Genesis, Game Boy) and 2D pixel-art indie games.
  • Limitations: If scaled to non-integer multiples (such as stretching a 240p source by 4.5x instead of 4x or 5x), nearest-neighbor can cause "pixel shimmering" or uneven pixel widths during horizontal or vertical movement.

How Bilinear Interpolation Works

Bilinear interpolation is a continuous resampling algorithm. When scaling up, it samples the four nearest pixels (a 2x2 grid) from the source image, calculates a weighted average based on their relative distances to the target coordinate, and creates a newly calculated blend of colors.

  • Aesthetic Result: Hard edges are eliminated in favor of smooth, gradual color transitions. For low-resolution raster graphics, this results in a cloudy, out-of-focus appearance commonly referred to as "vaseline over the screen."
  • Best Use Case: It works well for continuous-tone imagery, live camera feeds, and modern 3D games where hard pixel boundaries are unwanted artifacts.
  • Limitations: It actively destroys the geometric definition and stylistic sharpness that define 8-bit and 16-bit retro graphics.

Direct Comparison for Retro Content

Feature Point (Nearest-Neighbor) Bilinear Interpolation
Edge Sharpness Completely sharp; zero blur Softened, blended transitions
Color Fidelity Retains original, exact color palette Introduces hybrid gradient colors
Pixel Grid Preservation Preserved Eliminated/Smudged
Motion Clarity Crisp, but prone to jitter on non-integer scales Uniformly soft throughout motion
Computational Overhead Extremely low Very low, but slightly higher than Point

Applying the Settings in OBS Studio

OBS Studio defaults to bilinear filtering for most captured sources to prevent aliasing on standard video feeds. To switch to nearest-neighbor for a retro game capture:

  1. Right-click the game capture, window capture, or capture card source in the Sources list.
  2. Hover over Scale Filtering.
  3. Select Point.

To avoid uneven pixel distortion when using Point filtering, ensure the source is scaled using integer scaling factors (e.g., 200%, 300%, 400%) or positioned using canvas dimensions that divide evenly into the source's native resolution.
