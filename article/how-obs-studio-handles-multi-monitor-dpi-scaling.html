How OBS Studio Handles Multi-Monitor DPI Scaling

When dragged across monitors with different Windows display scaling factors, OBS Studio avoids the blurry legacy DPI virtualization typically applied to older desktop apps by operating as a Per-Monitor DPI-aware application. Instead of allowing Windows to bitmap-stretch its interface, OBS Studio dynamically reconfigures its user interface via the Qt framework and adjusts its internal rendering pipelines in response to operating system events. This ensures that UI text, dockable panels, and the central preview canvas remain sharp and correctly proportioned across varying scale factors (such as 100% to 150% or 200%).

Per-Monitor DPI Awareness (V2)

Windows handles legacy applications through standard DPI virtualization, where the OS renders the application off-screen at a system-wide baseline (usually 96 DPI / 100%) and then scales the window up or down using a bitmap filter. This results in noticeable blurring when an app is displayed on a high-DPI screen.

OBS Studio bypasses this behavior by declaring Per-Monitor V2 DPI awareness (DPI_AWARENESS_CONTEXT_PER_MONITOR_AWARE_V2) in its application manifest. Under this mode:

  • Windows disables automatic bitmap virtualization.
  • The OS delegates the responsibility of scaling to the application itself.
  • Windows delivers scaling and metric change notifications directly to the application message loop whenever the window crosses monitor boundaries.

The WM_DPICHANGED Message

When the center point or majority of the OBS Studio window crosses from one display to another with a differing scale factor, Windows issues a WM_DPICHANGED message to the main window handle.

This message provides two critical pieces of data:

  1. The New DPI Value: Stored in the WPARAM, indicating the horizontal and vertical DPI of the target monitor.
  2. A Suggested Window Rectangle (RECT): Stored in the LPARAM, representing the newly scaled window dimensions and position calculated by Windows to ensure a smooth transition.

OBS Studio processes this message to resize its outer window frame according to the recommended rectangle, preventing sudden visual jumps or clipping during the transition.

UI Adaptation Through the Qt Framework

OBS Studio builds its graphical interface using the Qt framework (Qt 6 in modern releases). Qt sits directly above the Win32 API layer and translates low-level DPI messages into internal layout updates:

  • Asset Swapping and Rescaling: High-resolution icons and vector assets (SVGs) are redrawn at the native pixel density of the target monitor.
  • Font and Metric Recalculation: Point sizes for fonts are converted to physical pixel sizes using the new DPI, triggering a recalculation of all layout managers, margins, and padding.
  • Dock Widget Reorganization: OBS Studio’s modular panels (Scenes, Sources, Audio Mixer, Controls) adapt their geometries simultaneously, ensuring text and sliders do not overflow or overlap.

Decoupling the UI from the Canvas Viewport

A distinct challenge in OBS Studio is maintaining video preview accuracy while the surrounding interface scales. OBS Studio decouples its Qt-based UI from its core graphics rendering engine (Direct3D 11 on Windows):

  • Canvas Render Targets: The internal composition canvas (the video output resolution, such as 1920x1080 or 3840x2160) remains fixed in memory and is entirely independent of the monitor's scaling factor.
  • Viewport Presentation: The preview area embedded in Qt is backed by a native Win32 child window (HWND). When the parent window moves between monitors, the graphics subsystem resizes the Direct3D swapchain to match the new physical pixel dimensions of the preview panel, but it does not alter the underlying source coordinates.
  • Mouse Coordinate Mapping: To allow users to select, transform, and crop sources on the preview regardless of DPI, OBS normalizes cursor screen coordinates using the current monitor scale factor before mapping them onto the internal canvas coordinate space. This maintains pixel-accurate manipulation across different monitors.
