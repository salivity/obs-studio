How OBS Studio Updates Fonts Without Restarting

OBS Studio handles external font updates dynamically by relying on operating system font subsystems and just-in-time font enumeration, allowing creators to install and use new typography without closing their active streaming or recording sessions. By querying system font registries whenever the text configuration interface is accessed, OBS avoids static font caching and immediately recognizes newly registered fonts across Windows, macOS, and Linux.

OS-Level Font Registry Integration

When an external font file (such as .ttf or .otf) is installed, the operating system registers the font within its central font table. On Windows, the OS typically broadcasts a WM_FONTCHANGE message to top-level windows to notify running software that the system font pool has changed. macOS and Linux handle this through Core Text and Fontconfig respectively.

OBS Studio does not maintain an isolated, persistent internal font cache that requires an application-level reload. Instead, it acts as an interface that communicates directly with the underlying platform APIs:

  • Windows: DirectWrite or GDI+ (depending on the text plugin used).
  • macOS: Core Text framework.
  • Linux: FreeType 2 combined with Fontconfig.

Just-in-Time Font Enumeration

Rather than scanning the entire system font library only once during initial launch, OBS Studio utilizes just-in-time font enumeration inside its text source plugins (such as text-gdiplus or text-freetype2).

When a user clicks Select Font inside the Text Source properties:

  1. OBS calls the operating system's native font dialog or invokes an API call to retrieve the active list of registered font families.
  2. The operating system returns the current state of its font table, which now includes the newly installed font.
  3. The font selection dropdown updates immediately to reflect the new additions.

Source-Level Reinitialization

If a text source is already active in a scene, OBS Studio maintains the current font in memory until the source settings are modified. Opening the properties of that specific text source forces the plugin to re-read available font descriptors. Once the new font is selected and confirmed by clicking OK, the text rendering engine frees the old font resources, loads the newly selected font metrics into the rendering pipeline, and immediately renders the updated vector paths onto the scene canvas.

Best Practices for Seamless In-Session Updates

To ensure OBS Studio detects newly installed fonts without interruptions:

  • Install for All Users (Windows): Right-click the font file and select "Install for all users" to ensure the font registers globally in C:\Windows\Fonts, making it immediately accessible to standard API queries.
  • Reopen the Properties Window: If a text source properties panel is already open while installing a font, close the dialog and open it again to force OBS to query the OS font list anew.
