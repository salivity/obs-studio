OBS Studio Crop Pad Filter Algorithm Explained

This article provides an overview of how the Crop/Pad filter in OBS Studio alters source coordinates without modifying the source resolution. It details the underlying texture coordinate remapping and vertex transformation algorithms utilized by the OBS rendering engine, explaining how source fidelity is preserved across the rendering pipeline.

Texture Coordinate (UV) Remapping

When modifying canvas coordinates without altering source resolution, the OBS Studio Crop/Pad filter (plugins/obs-filters/crop-filter.c) does not employ traditional spatial resampling algorithms, such as Bilinear, Bicubic, or Lanczos. Instead, it uses Affine Texture Coordinate Remapping (UV mapping).

In GPU rendering pipelines, 2D textures are mapped to geometry via normalized UV coordinates ranging from 0.0 to 1.0. When crop values are applied, the filter recalculates these normalized boundaries mathematically:

  • U_start = crop_left / source_width
  • U_end = (source_width - crop_right) / source_width
  • V_start = crop_top / source_height
  • V_end = (source_height - crop_bottom) / source_height

By adjusting the UV mapping bounds rather than processing raw pixel matrices, the filter instructs the graphics subsystem (obs-graphics) to sample only a specific subregion of the source texture.

Vertex Coordinate Transformation

For the spatial placement on the canvas, the Crop/Pad filter alters vertex buffer positions via Orthographic Matrix Transformation.

  1. Cropping: The geometric quad representing the source is reduced in size to match the cropped dimensions (width - crop_left - crop_right and height - crop_top - crop_bottom). The vertices are recomputed directly in local coordinate space, creating an axis-aligned bounding box (AABB) that clips the unselected texels without downsampling or rasterizing the source.
  2. Padding: When negative crop values are entered (padding), the filter expands the local vertex boundaries. The texture UVs remain mapped exclusively across the original dimensions, while the remaining expanded quad area is left transparent or drawn as transparent black via alpha blending, translating the coordinates within the scene.

Direct Texel-to-Pixel Mapping

Because UV coordinate remapping and vertex transformation operate purely on geometry rather than pixel interpolation, the native pixel structure remains intact. The source texels are passed directly to the render target with a 1:1 texel-to-pixel ratio. Spatial interpolation algorithms are only triggered downstream if secondary filters or canvas scaling transforms are explicitly applied to the scene item.
