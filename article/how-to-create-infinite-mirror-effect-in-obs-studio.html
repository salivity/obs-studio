How to Create Infinite Mirror Effect in OBS Studio

Creating an infinite mirror effect—also known as a video feedback loop—in OBS Studio is a simple visual technique where your screen recursively captures itself into infinity. This article provides a quick, step-by-step guide on how to intentionally trigger, configure, and customize this hypnotic cascading screen effect for your live streams or video recordings.

Step 1: Add a Display Capture Source

The infinite mirror effect relies on OBS capturing the very screen that is displaying the OBS interface.

  1. Open OBS Studio.
  2. In the Scenes dock, select the scene where you want the effect.
  3. In the Sources dock, click the + (plus) icon and select Display Capture.
  4. Name the source and click OK.

Step 2: Select the Active Monitor

A properties window will appear. Under the Display dropdown menu, you must select the monitor where the OBS Studio window is currently open. If you have a single-monitor setup, this will happen automatically. Click OK to save the settings.

Step 3: Enable the Loop

To make the loop infinite, you must keep the OBS Studio application visible on the screen being captured.

  • Do not minimize OBS Studio.
  • Do not move the OBS Studio window to a second, uncaptured monitor. As long as the OBS preview window is visible on the captured display, it will continuously capture itself, creating the endless tunnel effect.

Step 4: Customize the Effect (Optional)

You can modify the standard feedback loop to create unique, stylized visuals:

  • The Spiral Effect: Right-click your Display Capture source, go to Transform, and select Edit Transform. Add a slight rotation (e.g., 2 or 3 degrees) or slightly shrink the size. This causes the infinite tunnel to twist or spiral into the distance.
  • The Color Shift: Right-click the Display Capture source, select Filters, and click the + icon to add a Color Correction filter. Adjust the hue, saturation, or contrast. Because the filter is applied to each successive capture, the colors will progressively shift and intensify deeper into the loop.
