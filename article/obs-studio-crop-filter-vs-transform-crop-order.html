OBS Studio Crop Filter vs Transform Crop Order

When both a Crop/Pad filter and a Transform crop are applied to the same source in OBS Studio, the Crop/Pad filter is processed first, followed by the Transform crop. Understanding this internal pipeline order is essential for managing source resolutions, maintaining correct aspect ratios, and ensuring that downstream visual effects render predictably.

The OBS Studio Rendering Pipeline

OBS Studio processes visual data in a strict hierarchical order, moving from the raw source level up to the final scene composition. The execution order between the two cropping methods works as follows:

  1. Source Generation: OBS captures or generates the raw media frame (such as a video capture device, window capture, or media file) at its native resolution.
  2. Filter Chain Execution (Source Level): OBS executes any filters attached directly to the source. The Crop/Pad filter resides within this chain. The software creates a new, resized texture based on the pixels removed or added by the filter.
  3. Scene Item Transform (Scene Level): Once the source-level filters have processed the texture, the result is handed off to the scene item. The Transform crop (adjusted via "Edit Transform" or by holding the Alt key while dragging bounding box handles) is calculated at this stage. It clips the already-filtered texture before applying scaling, rotation, and positioning within the scene canvas.

Key Differences and Behavioral Impact

Because the Crop/Pad filter operates prior to the Transform crop, each method affects the pipeline differently:

  • Resolution and Coordinate Space: The Crop/Pad filter permanently alters the source's output dimensions before the scene sees it. Any subsequent Transform crop operates on these newly reduced dimensions rather than the original capture resolution.
  • Filter Stacking: Other source-level filters placed after the Crop/Pad filter (such as Color Correction, Sharpen, or Blur) only process the cropped pixels, saving GPU resources. In contrast, a Transform crop occurs after all source filters, meaning the GPU renders effects across the entire pre-transform area before clipping it from the canvas.
  • Global vs. Instance Application: The Crop/Pad filter affects every instance of the source across all scenes. The Transform crop is strictly a scene-item property, allowing you to crop a single source differently across multiple scenes without changing the underlying source dimensions.
