Stream to YouTube with HLS in OBS Studio

This guide provides a straightforward, step-by-step walkthrough on how to configure OBS Studio to stream to YouTube using the HTTP Live Streaming (HLS) protocol. Transitioning from RTMP to HLS allows you to stream in higher-efficiency codecs like HEVC (H.265) or AV1, which deliver superior video quality, HDR support, and better stability at lower bandwidths.

Step 1: Enable HLS in YouTube Control Room

Before configuring OBS, you must set up an HLS-compatible stream key in your YouTube account.

  1. Go to the YouTube Studio dashboard and click Go Live in the top right corner.
  2. In the Live Control Room, navigate to the Stream Settings tab.
  3. Under Stream key selection, click the dropdown and select Create new stream key.
  4. Name your stream key and ensure the Stream Protocol is set to HLS (highly recommended).
  5. If you want to stream in HDR, toggle the Turn on manual resolution/frame rate selection and select your desired resolution (e.g., 4K or 1440p).
  6. Copy the Stream Key generated by YouTube.

Step 2: Configure Stream Settings in OBS Studio

Next, you need to point OBS Studio to YouTube's HLS ingestion servers.

  1. Open OBS Studio and click Settings in the bottom right corner.
  2. Select the Stream tab from the left-hand menu.
  3. Click the Service dropdown menu and select YouTube - HLS.
  4. Keep the Server set to Primary YouTube Ingest Server.
  5. Click Use Stream Key, paste the stream key you copied from YouTube into the text field, and click Apply.

(Alternatively, you can click "Connect Account" to sign in directly, which automatically configures the HLS connection.)

Step 3: Optimize Video Encoder Settings for HLS

HLS achieves its high efficiency by utilizing modern video encoders. You must configure OBS to use HEVC or AV1 instead of the older H.264 encoder.

  1. In the Settings window, click on the Output tab.
  2. Change the Output Mode dropdown at the top to Advanced.
  3. Under the Streaming tab, locate the Video Encoder option.
  4. Select one of the following modern encoders based on your hardware:
    • NVIDIA NVENC HEVC or NVIDIA NVENC AV1 (for NVIDIA graphics cards)
    • AMD HW H.265 or AMD HW AV1 (for AMD graphics cards)
    • SVT-AV1 or AOM AV1 (CPU-based AV1 encoders, resource-intensive)
  5. Set your Rate Control to CBR (Constant Bitrate).
  6. Set your Bitrate according to your target resolution:
    • 1080p (60fps): 6,000 to 10,000 Kbps
    • 1440p (60fps): 10,000 to 15,000 Kbps
    • 4K (60fps): 20,000 to 30,000 Kbps
  7. Set the Keyframe Interval to exactly 2 s (2 seconds). This is a critical requirement for HLS streaming.
  8. Click Apply.

Step 4: Configure Video Resolution

  1. Navigate to the Video tab in the Settings window.
  2. Set the Base (Canvas) Resolution to match your monitor's resolution.
  3. Set the Output (Scaled) Resolution to match the target resolution you chose in Step 3.
  4. Set the Common FPS Values to 60 (or 30 depending on your preference).
  5. Click OK to save all settings.

Step 5: Start the Stream

  1. Click Start Streaming in the main OBS Studio window.
  2. Go back to your YouTube Live Control Room in your web browser.
  3. Within a few seconds, YouTube will begin receiving the HLS feed, displaying a preview and indicating an "Excellent Connection" status.
  4. If your stream is not set to auto-start, click Go Live in the YouTube Control Room to begin broadcasting to your viewers.
