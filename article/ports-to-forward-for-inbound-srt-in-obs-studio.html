Ports to Forward for Inbound SRT in OBS Studio

This article provides a direct guide on configuring corporate firewalls to receive incoming Secure Reliable Transport (SRT) video streams directly into OBS Studio. You will learn the exact network protocol, port requirements, firewall rule configurations, and OBS listener parameters necessary to establish a stable, low-latency live video connection from remote contributors.

The Required Port and Protocol

SRT operates exclusively over the UDP (User Datagram Protocol). TCP port forwarding will not work for SRT streams.

  • Protocol: UDP
  • Default/Standard Port: UDP 9998 (or any user-defined unprivileged port between 1024 and 65535, such as UDP 9000 or UDP 10000)

Because SRT does not have an officially mandated single port, the required port depends on the port configured in the OBS Studio source. However, UDP port 9998 is the community standard and most commonly used default for OBS Studio SRT listeners.

Corporate Firewall and NAT Configuration

To accept an external SRT contribution feed, the corporate edge firewall must forward the inbound UDP traffic to the local network IP address of the workstation running OBS Studio.

  1. Port Forwarding (DNAT):

    • Source IP: Any (or restricted to the remote contributor’s specific public IP address for security).
    • Source Port: Any / Ephemeral.
    • Destination/Listen Port: UDP 9998 (or your chosen port).
    • Target/Internal IP: Static internal IP address of the OBS Studio host machine.
    • Target/Internal Port: UDP 9998 (must match the external listen port unless port translation is intentionally used).

  2. Access Control Lists (ACLs):

    • Create an inbound firewall rule permitting incoming UDP traffic on the specified port from the WAN interface to the OBS workstation's LAN IP.
    • Restrict access by whitelisting only the remote broadcaster’s WAN IP if your corporate security policy strictly limits open inbound ports.

OBS Studio Configuration

To accept the incoming connection, OBS Studio must be configured in listener mode:

  1. Add a Media Source or VLC Video Source in OBS Studio.
  2. Uncheck Local File.
  3. In the Input field, enter: srt://0.0.0.0:9998?mode=listener (Using 0.0.0.0 instructs OBS to bind to all local network interfaces on UDP port 9998.)
  4. Ensure the remote contributor sets their SRT encoder to caller mode pointing to your corporate public IP address: srt://[Corporate-Public-IP]:9998?mode=caller

Local Host Firewall

In addition to the corporate perimeter firewall, ensure the local software firewall (such as Windows Defender Firewall or macOS Packet Filter) on the OBS workstation allows inbound UDP traffic on port 9998 for the OBS Studio executable.
