HDR Tone-Mapping Above 1000 Nits in OBS Studio

OBS Studio manages high dynamic range (HDR) signals exceeding 1000 nits by using shader-based tone-mapping curves, specifically ACES (Academy Color Encoding System) and Reinhard operators, executed directly on the GPU. When high-luminance content exceeds standard mastering targets or is downscaled for standard dynamic range (SDR) distribution, OBS converts non-linear color signals into linear light, applies a non-linear shoulder compression to extreme highlight values, and reconstructs the color to prevent clipping, preserve local contrast, and avoid color-channel blowout.

Linear Light Conversion

Before OBS Studio applies any compression to pixel values, it converts incoming HDR video feeds—typically encoded using the Rec. 2100 standard via Perceptual Quantizer (PQ / SMPTE ST 2084) or Hybrid Log-Gamma (HLG)—into linear color space. In this linear floating-point representation, pixel values correlate directly to real-world light intensity measured in nits (\(cd/m^2\)), where 1.0 represents SDR diffuse white (typically anchored to 80, 100, or 300 nits depending on the pipeline configuration), and values exceeding 1000 nits represent values far above unity.

The Compression Curve and Shoulder Roll-Off

Highlights above 1000 nits are compressed using mathematical transfer curves rather than hard clipping. OBS Studio implements two primary methods within its rendering pipeline:

  • ACES Filmic Tonemapping: OBS utilizes an approximation of the ACES curve to provide a photographic roll-off. This algorithm maintains a linear 1:1 response across shadows and midtones, but introduces a soft "knee" where the curve transitions smoothly as luminance approaches and surpasses 1000 nits. The curve asymptotes toward the target peak white, compressing thousands of nits of specular highlights into the upper dynamic range of the output target without creating a hard boundary.
  • Reinhard Tone-Mapping: OBS also allows for Reinhard-based compression, which uses a rational function (\(L_{out} = \frac{L_{in}}{1 + L_{in}}\)). When applied with an extended peak parameter, it scales highlight values logarithmically. This ensures that an extreme value (e.g., a 4000-nit sun reflection) is smoothly mapped into the available headroom without crushing the adjacent sub-1000-nit details.

Preserving Hue and Saturation

A common issue with high-nit highlight compression is "channel clipping," where an intense light source pushes one color channel (often green or red) past the limit first, causing color shifts toward white, yellow, or magenta.

To mitigate this, OBS computes the tone-mapping operator over total luminance or a weighted scalar value rather than evaluating the Red, Green, and Blue channels independently:

  1. Luminance Extraction: The shader calculates the relative perceptual luminance (\(Y\)) of the pixel using standard Rec. 2020/2100 luminance coefficients (\(Y = 0.2627R + 0.6780G + 0.0593B\)).
  2. Scalar Compression: The tone-mapping curve is applied strictly to this luminance value, determining a uniform scale factor: \[\text{Scale} = \frac{Y_{compressed}}{Y_{original}}\]
  3. Color Reconstruction: Each individual RGB component is multiplied by this uniform scale factor. This maintains the original ratio between color channels, preserving both the chromaticity and the intended hue of specular highlights even when the overall brightness is heavily compressed.

Output Remapping

Once the highlights over 1000 nits have been compressed into the target domain, OBS Studio reconverts the linear values back into the desired output format:

  • HDR-to-HDR (Targeted Mastering): If streaming or recording in HDR to a 1000-nit display limit, highlights up to 4,000 or 10,000 nits are packed into the available 1000-nit PQ/HLG dynamic range.
  • HDR-to-SDR: When down-mapping HDR content for standard Rec. 709 streams, the dynamic range above 1000 nits is rolled into the uppermost tier of the 0–100 nit range, followed by a color gamut mapping step that transforms Rec. 2020 coordinates into Rec. 709 boundaries without clipping out-of-gamut colors.
