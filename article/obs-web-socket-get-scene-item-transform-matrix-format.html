OBS WebSocket GetSceneItemTransform Matrix Format

This guide outlines the data format returned by the GetSceneItemTransform request in the OBS Studio WebSocket API (version 5.x). Rather than outputting a raw, flattened mathematical matrix array, the API returns a structured JSON object containing discrete 2D affine transformation parameters—such as position, scale, rotation, alignment, and crop values—which can be directly mapped into a standard 3×3 transformation matrix.

Response Data Structure

When executing GetSceneItemTransform, the OBS WebSocket server responds with a sceneItemTransform object containing the following primary properties:

  • positionX (number): The horizontal coordinate of the item's anchor point on the canvas.
  • positionY (number): The vertical coordinate of the item's anchor point on the canvas.
  • scaleX (number): The horizontal scale multiplier (1.0 represents 100% scale).
  • scaleY (number): The vertical scale multiplier (1.0 represents 100% scale).
  • rotation (number): The clockwise rotation angle measured in degrees.
  • alignment (integer): An OBS alignment bitmask that defines the anchor/origin point of the item:
    • 0: Center
    • 1: Left
    • 2: Right
    • 4: Top
    • 8: Bottom
    • Combinations are summed (e.g., Top-Left is 5, Center is 0).
  • sourceWidth / sourceHeight (number): The unscaled base dimensions of the source.
  • width / height (number): The rendered dimensions on the canvas after scaling and cropping.
  • cropLeft, cropRight, cropTop, cropBottom (integer): Pixel values trimmed from each edge before scaling.
  • boundsType, boundsWidth, boundsHeight, boundsAlignment: Parameters governing how the source fits inside a bounding box if enabled.

Constructing the 2D Affine Matrix

To convert these properties into a standard 3×3 affine transform matrix for 2D rendering or coordinate projection:

\[\begin{bmatrix} a & c & t_x \\ b & d & t_y \\ 0 & 0 & 1 \end{bmatrix}\]

  1. Convert Rotation to Radians: \[\theta = \text{rotation} \times \left(\frac{\pi}{180}\right)\]

  2. Compute Matrix Coefficients:

    • \(a = \text{scaleX} \times \cos(\theta)\)
    • \(b = \text{scaleX} \times \sin(\theta)\)
    • \(c = -\text{scaleY} \times \sin(\theta)\)
    • \(d = \text{scaleY} \times \cos(\theta)\)
    • \(t_x = \text{positionX}\)
    • \(t_y = \text{positionY}\)

Anchor Point Adjustment

The translation coordinates (\(t_x, t_y\)) map to the anchor point defined by the alignment field. If mapping to the source’s local origin (top-left \((0,0)\) without alignment offset), calculate the local pivot offset based on sourceWidth and sourceHeight (less crops), then multiply the pivot offset through the matrix to establish absolute world-space corners.
