Configuring OBS Custom Canvas for Ribbon Boards

Specialized esports stadium ribbon boards utilize extremely wide, non-standard aspect ratios that standard 16:9 broadcast configurations cannot properly drive. OBS Studio supports these ultra-wide LED formats by enabling operators to manually define custom canvas dimensions, bypass default aspect ratio locks, scale graphic layouts precisely, and route specialized video feeds directly to stadium LED processors. This guide explains how to configure OBS Studio to render, monitor, and deliver custom aspect ratio content for stadium ribbon board displays without stretching or resolution loss.

Determining Ribbon Board Pixel Dimensions

Esports ribbon boards wrap along arena balconies, fascia, and desk perimeters, demanding unusual pixel maps such as 3840x216, 7680x360, or 1920x108. Before configuring OBS Studio, obtain the exact active pixel map from the arena LED processor engineers (such as NovaStar, Brompton, or Megapixel VR). Do not approximate dimensions; custom ribbon boards require 1:1 pixel accuracy to prevent blurred graphics, scaling artifacts, and alignment shifts.

Overriding the Default Canvas Resolution

OBS Studio allows users to manually type custom dimensions into resolution fields rather than selecting from the standard preset menu.

  1. Open OBS Studio and open Settings.
  2. Select the Video tab from the left sidebar.
  3. Highlight the text in the Base (Canvas) Resolution field.
  4. Type your exact ribbon board dimensions directly into the field (e.g., 3840x216).
  5. Highlight the Output (Scaled) Resolution field and type the exact same dimensions to maintain 1:1 pixel mapping without GPU downscaling.
  6. Set the Common FPS Values to match the stadium display refresh rate, typically 60 or 59.94 FPS.
  7. Click Apply and then OK.

The OBS Studio preview window will immediately reconfigure into an ultra-wide, horizontal strip reflecting your designated dimensions.

Navigating the Ultra-Wide Preview Window

Working in an extreme horizontal workspace presents monitoring challenges on standard desk monitors.

  • Preview Scaling: Right-click inside the gray area surrounding the preview canvas and select Scale to Window to view the entire strip.
  • Full-Width Zooming: If detailed placement is required, right-click the canvas, choose Preview Scaling, and select Canvas (1:1). Use horizontal scrollbars to maneuver across the strip when fine-tuning lower-thirds, sponsor carousels, or game-state banners.
  • Locking Sources: Because thin strips are prone to accidental drag inputs, lock all active layers in the Sources dock using the padlock icon once assets are aligned.

Setting Up Scene Architecture for Stadium Displays

Stadium graphics systems must dynamically respond to live game events such as team victories, objective captures, and player kills.

  1. Create Dedicated Scene Collections: Go to Scene Collection > New and title it after the specific ribbon board to isolate these non-standard resolutions from your main broadcast configuration.
  2. Import 1:1 Assets: Ensure dynamic motion graphics, media files, and stinger overlays match the canvas width and height. Avoid using standard 1920x1080 video sources scaled down, as this wastes GPU resources and causes horizontal distortion.
  3. Configure Edge Snapping: Go to Settings > General > Source Alignment Snapping. Enable snapping to screen edges and set the sensitivity to 10 pixels. This guarantees graphic assets sit flush against ribbon borders.

Routing Video to Arena Processors

Once the canvas is designed, the feed must be delivered to the stadium's physical LED processor.

  • Direct GPU Projector: Connect a dedicated GPU output from the OBS machine to the LED processor's input card. Right-click the OBS preview window, navigate to Fullscreen Projector (Preview) or Fullscreen Projector (Program), and select the designated stadium display output.
  • NDI Output: If the stadium routing environment operates over IP, install the OBS-NDI plugin. Navigate to Tools > NDI Output Settings, enable the main output, and route the uncompressed custom video feed across the venue network to the media server driving the ribbon wall.
  • DeckLink / SDI Capture Cards: For broadcast facilities utilizing SDI routers, use an internal Blackmagic DeckLink card. Navigate to Tools > DeckLink Output, select the dedicated hardware channel, and match the keyer settings to your LED processor input expectations.

Managing Hardware Limits on Ultra-Wide Feeds

Consumer and professional GPUs impose maximum horizontal and vertical resolution ceilings. If a continuous ribbon board exceeds maximum horizontal constraints (such as exceeding 16,384 horizontal pixels), the display must be configured as a multi-tier split canvas.

In this scenario, divide the ribbon into stacked tiers inside a standard 4K canvas (e.g., two 7680x180 strips stacked vertically inside a 7680x360 canvas) in OBS Studio. The stadium's downstream hardware processor is then configured to unpack and place the stacked outputs end-to-end along the physical ribbon display.
