CSS Selectors for OBS Browser Source Styling

Using Custom CSS within an OBS Studio Browser Source allows streamers to strip unwanted website clutter, isolate specific widgets, and re-theme web pages directly inside their broadcast canvas. By leveraging targeted CSS selectors—such as IDs, classes, attribute selectors, and structural pseudo-classes—you can target distinct Document Object Model (DOM) elements to hide advertisements, remove navigation bars, make backgrounds transparent, or highlight specific live data.

Identifying Selectors with Developer Tools

Before applying styles in OBS, open the target URL in a standard browser (like Chrome or Firefox), right-click the item you want to modify, and select Inspect. This reveals the page's HTML structure, class names, and IDs needed to write the selectors below.

Core Selectors for Isolating Elements

1. The ID Selector (#id)

IDs are unique to a single element per page, making them the most reliable selector for targeting specific containers such as a chat window, a score tracker, or a main video frame.

#chat-messages {
    background: transparent !important;
    font-size: 18px;
}

2. The Class Selector (.class)

Class selectors target one or more elements sharing the same class name. In OBS, this is typically used to hide UI noise such as headers, footers, or cookie consent banners.

.site-header, .sidebar, .cookie-banner {
    display: none !important;
}

3. Attribute Selectors ([attribute="value"])

Many modern web applications use dynamic, randomized class names (e.g., generated by CSS-in-JS frameworks). Attribute selectors allow you to target elements by stable attributes like aria-label, data-testid, role, or partial attribute values.

  • Exact Match: Target an element with a specific role or data attribute. 
    div[data-testid="user-avatar"] {
    border-radius: 50%;
}
  • Contains Match (*=): Target an element containing a specific string anywhere in its class or ID. 
    div[class*="chat-line"] {
    margin-bottom: 4px;
}
  • Starts-With Match (^=): Target an attribute starting with a defined prefix. 
    div[id^="stream-overlay-"] {
    position: absolute;
    top: 0;
}

4. Structural Pseudo-Classes

Pseudo-classes let you isolate elements based on their position in the document tree rather than their attributes.

  • :nth-child() and :nth-last-child(): Ideal for isolating dynamic lists, such as keeping only the latest chat messages or highlighting the top row of a leaderboard. 
    /* Hides all messages except the last 5 in a chat log */
.chat-list > div:not(:nth-last-child(-n+5)) {
    display: none !important;
}
  • :first-child and :last-child: Target the beginning or end of a sequence. 
    .leaderboard-entry:first-child {
    color: gold;
    font-weight: bold;
}
  • :not() (Negation): Style or display everything except elements matching a specific condition. 
    /* Hide all buttons except the submission button */
button:not(.submit-btn) {
    display: none !important;
}

Isolating a Single Component on a Web Page

To show only one component on a full web page while hiding everything else, combine the universal selector (*) with the visibility property:

/* Make background transparent */
body {
    background-color: rgba(0, 0, 0, 0) !important;
    overflow: hidden;
}

/* Hide all elements by default */
body * {
    visibility: hidden;
}

/* Make only the target element and its children visible */
#target-widget, #target-widget * {
    visibility: visible;
}

/* Reposition the target element to the top-left of the OBS canvas */
#target-widget {
    position: fixed;
    top: 0;
    left: 0;
    z-index: 9999;
}

Using visibility: hidden instead of display: none preserves the page's original layout structure, preventing layout collapses or broken JavaScript functions while cleanly isolating the desired content.
