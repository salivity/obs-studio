OBS Studio NVENC CQP Calculation Explained

When utilizing Constant Quantization Parameter (CQP) rate control on NVIDIA graphics cards, OBS Studio does not dynamically calculate quantization values through an automated bitrate algorithm. Instead, the application takes a user-defined integer value and passes it directly to the NVIDIA Video Codec SDK (NVENC) as a static base parameter for video compression, bypassing dynamic bitrate budgeting entirely.

The Direct Mapping of Base QP

In standard rate-control modes like CBR (Constant Bitrate) or VBR (Variable Bitrate), an encoder constantly calculates the Quantization Parameter (QP) for each frame to maintain a specific target data rate over time. In CQP mode, this feedback loop is turned off.

OBS Studio provides an input field for the user to define a CQ level—typically ranging from 0 (lossless) to 51 (highest compression). When encoding begins, OBS sets the rate control mode in the NVENC API to NV_ENC_PARAMS_RC_CQP. It assigns the user's chosen value directly to the frame parameters:

  • I-Frame QP: Set directly to the specified user value.
  • P-Frame QP: Set directly to the specified user value.
  • B-Frame QP: Set directly to the specified user value.

In the standard OBS Studio interface, the same base quantization value is assigned uniformly across I, P, and B frames without programmatic scaling or complex mathematical offsets.

Hardware-Level Adjustments via Adaptive Quantization

While OBS Studio passes a fixed, static base QP to the NVIDIA driver, the actual quantization of individual macroblocks can still vary during encoding if specific secondary settings are enabled in OBS:

  • Spatial AQ (Adaptive Quantization): When checked, the NVENC hardware analyzes spatial detail across the image. It lowers the QP (retaining higher quality) on complex edges and textures, and raises the QP on flat or smooth surfaces where artifacts are less perceptible to the human eye.
  • Temporal AQ: When enabled, the hardware evaluates motion between consecutive frames. If a region remains static across multiple frames, NVENC lowers the QP to prevent macroblocking in low-motion areas, compensating by allowing slightly higher QP on high-motion elements.

Even with Spatial or Temporal AQ active, OBS Studio itself does not perform any calculations. The base value remains the exact number entered in the software, while the NVENC hardware adjusts block-level values relative to that base number.

Summary of the CQP Process

OBS Studio's role in CQP calculation on NVIDIA hardware is strictly passthrough:

  1. The user defines a single target quantization number in the output settings.
  2. OBS maps this integer to the initial configuration struct for the NVENC session.
  3. The NVENC hardware encodes each frame at that absolute compression level, only modulating the value at the block level if hardware-based Adaptive Quantization flags are explicitly toggled.
