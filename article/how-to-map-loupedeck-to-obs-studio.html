How to Map Loupedeck to OBS Studio

This guide outlines the step-by-step process for integrating a Loupedeck console with OBS Studio to manage real-time broadcasts efficiently. By linking Loupedeck’s configuration software with OBS Studio, creators can assign tactile controls to audio faders via rotary dials, execute instant scene cuts using physical buttons, and trigger media cues with dynamic touch pads.

Prerequisites and Initial Setup

  1. Install the latest versions of both OBS Studio and the Loupedeck Software.
  2. Open OBS Studio, navigate to Tools > WebSocket Server Settings, and ensure Enable WebSocket server is checked. Modern Loupedeck software uses this connection to communicate directly with OBS.
  3. Launch the Loupedeck software and ensure your device (such as the Loupedeck Live or Loupedeck CT) is detected.
  4. Select the OBS Studio profile from the top application drop-down menu in the Loupedeck configuration window.

Mapping Audio Faders to Dials

To manage levels for microphones, desktop audio, or alert sounds using physical rotary dials:

  1. In the Loupedeck software, navigate to a page containing dial controls.
  2. In the right-hand action panel, expand the OBS Studio service tab.
  3. Locate the Audio or Audio Mixer category.
  4. Drag the specific audio source (e.g., Desktop Audio or Mic/Aux) onto an empty dial slot.
  5. Loupedeck automatically maps rotary turning to volume adjustments.
  6. To enable muting, assign the Mute/Unmute action for that same source to the dial’s push-button function.

Mapping Scene Cuts to Buttons

To execute direct scene transitions using physical or touch buttons:

  1. Select the workspace or touch page where you want your scene buttons located.
  2. In the right-hand action panel under the OBS Studio tab, expand Scenes.
  3. Drag the desired scene (e.g., Starting Soon, Main Gameplay, or Intermission) onto an available button.
  4. When pressed during a live stream, the button switches OBS directly to that scene.
  5. If using OBS Studio Mode, locate the Studio Mode: Transition action under the OBS tab and map it to a central button to manually cut or fade between the preview and program feeds.

Mapping Media Cues

To trigger intro videos, stingers, sound effects, or background music:

  1. Ensure the media file is added as a Media Source within your OBS Studio scene.
  2. In the Loupedeck software, find the Media Sources or Sources section under the OBS Studio actions.
  3. Drag the target media source onto a touch button.
  4. Configure the button behavior: select Play/Pause, Restart, or toggle Source Visibility depending on how the media source is configured to play in OBS.
  5. The button display will automatically update to show the source name or an associated media icon for clear identification during production.
