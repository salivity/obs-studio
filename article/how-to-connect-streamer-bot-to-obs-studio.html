How to Connect Streamer.bot to OBS Studio

Connecting Streamer.bot to OBS Studio allows you to automate your live streams by triggering scene changes, toggling sources, and controlling filters based on viewer interactions. This step-by-step guide will show you how to link Streamer.bot directly to OBS Studio using the modern, built-in OBS WebSocket server, ensuring a stable and secure connection for your broadcast.

Step 1: Enable the WebSocket Server in OBS Studio

OBS Studio (version 28 and above) comes with a built-in WebSocket server. You do not need to install any external plugins.

  1. Open OBS Studio.
  2. Click on Tools in the top menu bar and select WebSocket Server Settings.
  3. Check the box to Enable WebSocket Server.
  4. Note the Server Port (the default port is 4455).
  5. Ensure Enable Authentication is checked (highly recommended for security).
  6. Click Show Connect Info to view your password, and copy it to your clipboard.
  7. Click Apply and then OK to save the settings.

Step 2: Add the OBS Connection in Streamer.bot

Once OBS is configured to broadcast its connection, you need to tell Streamer.bot where to look.

  1. Open Streamer.bot.
  2. Navigate to the Stream Apps tab at the top of the interface.
  3. Select the OBS sub-tab.
  4. Right-click anywhere inside the blank "Connections" pane and select Add.

Step 3: Configure the Connection Details

A settings window will appear where you must input your OBS connection details:

  1. Name: Give your connection a name (e.g., "OBS Studio").
  2. Version: Select v5.x (OBS v28 and newer uses WebSocket v5).
  3. Host: Leave this as 127.0.0.1 (or localhost) if Streamer.bot is running on the same computer as OBS.
  4. Port: Enter the port number from OBS (usually 4455).
  5. Password: Paste the security password you copied from OBS Studio.
  6. Auto Connect on Startup: Check this box so Streamer.bot connects automatically whenever you launch the software.
  7. Reconnect on Disconnect: Check this box to allow Streamer.bot to automatically restore the connection if it drops.
  8. Click OK to save the configuration.

Step 4: Establish the Connection

With the details saved, you are ready to link the two programs:

  1. Right-click your newly created connection in the Streamer.bot list.
  2. Click Connect.
  3. The connection status indicator should turn Green and display "Connected."

Streamer.bot is now successfully connected to OBS Studio, and you can begin creating actions to control your stream layout, sources, and media.
