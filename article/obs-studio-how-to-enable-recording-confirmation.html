OBS Studio: How to Enable Recording Confirmation

This article explains how to set up visual confirmation alerts when managing your recordings in OBS Studio. While OBS does not feature a native pop-up dialog box for starting a recording—a design choice meant to prevent capture delays—you can configure native pop-up confirmations for stopping recordings, enable highly visible on-screen indicators, and utilize system tray alerts to ensure you always know when your screen is being captured.

How to Enable Native Stop-Recording Confirmation Pop-Ups

To prevent accidentally ending a recording session, you can enable a native confirmation dialog box that asks if you are sure you want to stop.

  1. Open OBS Studio.
  2. Click on Settings in the bottom-right Controls dock (or go to File > Settings in the top menu).
  3. Make sure you are on the General tab in the left-hand sidebar.
  4. Scroll down to the Output section.
  5. Check the box next to "Show confirmation dialog when stopping recordings".
  6. (Optional) You can also check the boxes for "Show confirmation dialog when starting streams" and "Show confirmation dialog when stopping streams" here.
  7. Click Apply and then OK to save your changes.

How to Use Visual Indicators for Starting Recordings

Since there is no native start-up pop-up, you should familiarize yourself with OBS Studio's built-in visual cues to confirm a recording has successfully initiated:

  • The Status Bar Timer: As soon as you click "Start Recording," look at the bottom-right corner of the OBS window. You will see a solid red dot appear next to a running timer labeled REC: (e.g., REC: 00:00:05). If this timer is moving, OBS is actively recording.
  • The Pause Button: Once recording starts, a small pause icon (two vertical bars) will appear next to the "Stop Recording" button in the Controls dock.
  • System Tray Icons: You can set OBS to display a red recording status badge in your operating system's taskbar or system tray:
    1. Go to Settings > General.
    2. Scroll down to the System Tray section.
    3. Check the box to Enable the system tray icon.
    4. When recording is active, the OBS tray icon will change color or display a red notification dot.
