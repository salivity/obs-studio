OBS Studio FFmpeg Audio Resampler Default Flags

When configuring the Custom Output (FFmpeg) mode in OBS Studio, audio conversion and resampling are handled through FFmpeg's libswresample library. OBS Studio does not inject custom resampler flags by default in its source code; instead, it initializes the resampler using standard channel layouts, sample formats, and sample rates, leaving the specific resampling algorithm flags at their native FFmpeg default values. This guide explains how OBS Studio initializes audio resampling, lists the specific default flags inherited from FFmpeg, and details how to override them.

OBS Studio Resampler Initialization

In OBS Studio's custom FFmpeg output implementation, audio frame conversion is handled by initializing a SwrContext structure using swr_alloc_set_opts (or swr_alloc_set_opts2 in modern FFmpeg builds).

OBS passes the following baseline configuration derived from the OBS audio engine and the selected encoder settings:

  • Input and Output Channel Layout (e.g., stereo, 5.1 surround)
  • Input and Output Sample Format (e.g., planar float AV_SAMPLE_FMT_FLTP, signed 16-bit AV_SAMPLE_FMT_S16)
  • Input and Output Sample Rate (e.g., 44100 Hz, 48000 Hz)

Because OBS sets the log context and offsets to neutral values without appending explicit algorithmic properties, the resampling pipeline relies entirely on the default behavior defined in libswresample.

Default FFmpeg libswresample Flags Applied

When OBS invokes swr_init(), FFmpeg automatically applies the following default flags and parameters:

  • Resampler Engine (resampler): Defaults to swr (the native FFmpeg software resampler, rather than soxr).
  • Filter Type (filter_type): Defaults to cubic (cubic interpolation filter).
  • Filter Length (filter_size): Defaults to 16 taps (or 32 when Kaiser windowing is explicitly requested).
  • Phase Shift (phase_shift): Defaults to 10 (representing \(2^{10} = 1024\) filter polyphases for phase accuracy).
  • Cutoff Frequency Ratio (cutoff): Defaults to 1.0 (for standard sinc/cubic filtering) or 0.97 (when Kaiser windowing is active) of the Nyquist frequency.
  • Linear Interpolation (linear_interp): Defaults to 0 (disabled), meaning the resampler selects the nearest filter phase rather than linearly interpolating between polyphase filter entries.
  • Dither Method (dither_method): Defaults to 0 (none). If bit-depth reduction occurs (such as downscaling from 32-bit float to 16-bit integer PCM), triangular dither (SWR_DITHER_TRIANGULAR) may automatically engage depending on the target format configuration.
  • Dither Scale (dither_scale): Defaults to 1.0.

Channel Mixing and Matrix Defaults

If OBS Studio is set to downmix or upmix channel counts during custom FFmpeg output (such as downmixing 7.1 audio to stereo):

  • Center Downmix Level (clev): Multiplied by \(\approx 0.7071\) (\(-3\text{ dB}\)).
  • Surround Downmix Level (slev): Multiplied by \(\approx 0.7071\) (\(-3\text{ dB}\)).
  • LFE Mix Level (lfe_mix_level): Defaults to 0.0 (omitted from stereo mixes to prevent distortion).
  • Rematrix Volume (rmv): Defaults to 1.0.

Overriding Resampler Flags in OBS Studio

To apply non-default resampling parameters—such as higher-order filtering or SoX-based resampling—custom key-value pairs can be entered into the Audio Resampler Settings or Audio Encoder Settings field in the Custom Output window:

resampler=soxr cutoff=0.95 filter_size=32 linear_interp=1

Any options placed here are passed into the SwrContext via av_opt_set, overriding the standard defaults.
