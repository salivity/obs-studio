Record ProRes 422 in OBS Studio via VideoToolbox

This article provides a technical overview and step-by-step guide on how OBS Studio configures Apple’s VideoToolbox framework for hardware-accelerated ProRes 422 recording on macOS. It covers the underlying architecture connecting OBS to Apple Silicon media engines, the exact output settings required for pristine 10-bit capture, and essential performance considerations for high-bitrate video pipelines.

Understanding VideoToolbox in OBS Studio

Apple VideoToolbox is a low-level framework that provides direct access to hardware video encoders and decoders built into macOS hardware. On Apple Silicon chips (M-series Pro, Max, and Ultra variants), dedicated ProRes hardware accelerators encode and decode video streams natively without taxing the CPU or GPU cores.

OBS Studio accesses this pipeline via its native VideoToolbox encoder integration. When configured for ProRes, OBS formats incoming captured frames as Core Video pixel buffers (CVPixelBufferRef) and passes them to a VTCompressionSession. The VideoToolbox session handles colorspace transformation, 10-bit chroma subsampling, and frame compression, writing intra-frame encoded data directly to disk inside a QuickTime container.

Step-by-Step Configuration in OBS Studio

To configure OBS Studio to use hardware-accelerated ProRes 422 on macOS, adjust the output and color management settings as follows:

1. Configure Advanced Output Settings

  1. Open Settings in OBS Studio and navigate to the Output tab.
  2. At the top of the window, change the Output Mode dropdown from Simple to Advanced.
  3. Select the Recording tab.
  4. Set the Type to Standard.
  5. Change the Recording Format to Apple ProRes or QuickTime (.mov). ProRes streams must be encapsulated in a .mov container to maintain compatibility with editing software like Final Cut Pro, DaVinci Resolve, and Adobe Premiere Pro.

2. Select the VideoToolbox ProRes Encoder

  1. In the Video Encoder dropdown, select Apple ProRes (Hardware) (or the specific VideoToolbox ProRes listing present in your OBS build).
  2. Set the ProRes Profile to ProRes 422. This profile balances master-quality fidelity with manageable file sizes, retaining full 10-bit depth and 4:2:2 chroma subsampling.
  3. Leave rate control parameters to default if unavailable, as ProRes functions inherently via target visual quality and intra-frame quantization rather than standard streaming rate-control methods like CBR or VBR.

3. Set Color Formats for 10-bit Pipeline

ProRes 422 is a 10-bit format. To prevent OBS from truncating pixel data to 8-bit before it reaches the hardware encoder:

  1. Navigate to the Advanced tab in OBS Settings.
  2. Under the Video section, set Color Format to P010 (10-bit, 4:2:0) or I422 / I010 depending on your source capture devices.
  3. Set Color Space to Rec. 709 for Standard Dynamic Range (SDR) or Rec. 2100 (PQ/HLG) for High Dynamic Range (HDR).
  4. Set Color Range to Limited (broadcast standard) or Full, ensuring it matches your monitor and source inputs.

System and Storage Requirements

Because ProRes 422 is an intra-frame codec—meaning every frame is encoded as an individual, uncompressed-like keyframe—bandwidth requirements are substantial:

  • Bitrates: 1080p at 60 fps generates approximately 140–220 Mbps, while 4K at 60 fps easily exceeds 500–800 Mbps.
  • Storage Performance: Recording to mechanical hard drives or slow external USB drives can cause buffer overflow and dropped frames. Always direct the recording path to an internal APFS-formatted NVMe SSD or a high-speed external Thunderbolt/USB4 enclosure.
  • Hardware Availability: While base M-series processors (e.g., standard M1, M2, M3) support ProRes encoding via general VideoToolbox acceleration, dedicated ProRes encoding hardware engines are specifically found on Pro, Max, and Ultra variants, providing the lowest latency and virtually zero system load during recording.
