How to Download and Install OBS Studio on Windows

This guide provides a straightforward, step-by-step walkthrough on how to download and install OBS Studio on a Windows computer. You will learn how to safely acquire the official installer, navigate the setup wizard, and complete the initial configuration to prepare your system for screen recording or live streaming.

Step 1: Download the OBS Studio Installer

  1. Open your web browser and navigate to the official website: obsproject.com.
  2. Click on the blue Windows button. This will automatically start the download of the latest .exe installer file for your system.
  3. Wait for the download to complete. By default, the file will be saved to your "Downloads" folder.

Step 2: Run the Installer

  1. Locate the downloaded installer file (typically named OBS-Studio-Full-Installer-x64.exe) and double-click it.
  2. If a User Account Control (UAC) prompt appears asking for permission to run the file, click Yes.

Step 3: Complete the Installation Wizard

  1. The OBS Studio Setup window will open. Click Next to begin the process.
  2. Read the license agreement and click Next to agree and proceed.
  3. Choose the destination folder where you want OBS Studio to be installed. The default location is recommended. Click Install.
  4. The installation process will begin, which usually takes less than a minute.

Step 4: Launch and Set Up OBS Studio

  1. Once the installation is finished, ensure the box next to Launch OBS Studio is checked, then click Finish.
  2. Upon opening the program for the first time, the Auto-Configuration Wizard will appear.
  3. Choose whether you want to optimize the software for streaming, recording only, or virtual camera usage, then follow the remaining prompts to apply the recommended settings for your hardware.
