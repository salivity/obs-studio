Access Audio Volume Levels in OBS Studio Lua API

The OBS Studio Lua API allows developers to monitor real-time audio levels and construct custom VU meters through its dedicated volmeter (volume meter) subsystem. By creating a volume meter object, binding it to a target audio source, and registering a level callback, scripts can continuously receive magnitude and peak values for all active audio channels. These values can then be translated into decibels or linear percentages to drive dynamic on-screen graphics, source transforms, or custom text readouts within your scenes.

Creating and Attaching the Volume Meter

The core interface for reading audio metrics in the OBS API is the obs_volmeter_t object. To begin tracking an audio source, you must instantiate a volume meter using obs_volmeter_create and specify an audio fader type, typically OBS_FADER_LOG for logarithmic decibel scaling or OBS_FADER_CUBIC.

Once the meter is created, locate your target audio source using obs_get_source_by_name and attach it to the meter using obs_volmeter_attach_source.

local volmeter = obs.obs_volmeter_create(obs.OBS_FADER_LOG)
local source = obs.obs_get_source_by_name("Desktop Audio")

if source then
    obs.obs_volmeter_attach_source(volmeter, source)
    obs.obs_source_release(source)
end

Always release the source reference after attaching it, as the volume meter maintains its own internal reference.

Registering the Audio Callback

Volume level updates are pushed asynchronously to a callback function rather than being polled frame-by-frame. You attach a callback function to the meter using obs_volmeter_add_callback.

The registered function receives three float array pointers representing the audio channels (such as channel 0 for Left and channel 1 for Right):

  • Magnitude (mag): Represents the root-mean-square (RMS) level, ideal for smooth, averaged volume representation.
  • Peak (peak): Captures transient spikes in the signal, essential for standard VU meter peak indicators.
  • Input Peak (input_peak): Reflects the raw incoming audio signal prior to any faders or volume filters applied within OBS.
local function volmeter_callback(data, volmeter, mag, peak, input_peak)
    -- mag and peak are C arrays wrapped for Lua
    local left_peak = obs.float_array_getitem(peak, 0)
    local right_peak = obs.float_array_getitem(peak, 1)

    -- Process levels for visual display
    update_vu_display(left_peak, right_peak)
end

obs.obs_volmeter_add_callback(volmeter, volmeter_callback, nil)

Converting Raw Levels to Decibels

The values emitted in the callback are normalized scalar values between 0.0 and 1.0. To build an accurate VU meter, these values are typically converted to decibels using standard audio math:

\[\text{dB} = 20 \times \log_{10}(\text{level})\]

In Lua, a value of 1.0 equates to 0 dB (maximum volume before clipping), while values approaching 0.0 decay down toward -inf dB. You can set a noise floor threshold (commonly -60 dB) to clamp lower-bound values and prevent math errors with zero values:

local function to_db(val)
    if val <= 0.0001 then
        return -60.0
    end
    return 20.0 * math.log10(val)
end

Driving Visual VU Meters

Once converted, the numeric levels can manipulate visual elements directly within OBS:

  • Crop Filters: Modifying the right or top crop setting of a color source or image source to make a visual bar grow or shrink.
  • Transform Scaling: Adjusting the scale vector of a meter element using obs_sceneitem_set_scale.
  • Text Sources: Setting the text of a GDI+ or FreeType text source to display active decibel numbers.

Because audio callbacks run on an audio thread at high frequencies, avoid heavy API calls inside the callback directly. Instead, store the latest peak and magnitude values in global script variables, then apply the visual transforms inside the script_tick(seconds) function to sync updates directly with OBS rendering frames.

Memory Cleanup and Lifecycle

Failing to detach and destroy volume meters results in memory leaks and audio thread overhead. Always release callbacks and destroy meter instances inside the script lifecycle functions:

function script_unload()
    if volmeter then
        obs.obs_volmeter_remove_callback(volmeter, volmeter_callback, nil)
        obs.obs_volmeter_destroy(volmeter)
        volmeter = nil
    end
end
