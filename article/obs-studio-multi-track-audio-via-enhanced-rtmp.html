OBS Studio Multi-Track Audio via Enhanced RTMP

This article explains the technical pipeline OBS Studio uses to encode, package, and transmit multiple distinct language audio tracks over a single Enhanced RTMP (E-RTMP) connection. By leveraging the updated Enhanced RTMP specification spearheaded by the Veovera Software Organization (VSO), OBS Studio moves beyond the legacy RTMP limitation of a single stereo audio track. The process involves independent per-track encoding, track-specific metadata tagging, and multiplexed transmission over one network stream.

Legacy RTMP Limitations vs. Enhanced RTMP

Legacy RTMP was constrained by the Adobe Flash Media format, which accommodated only one video track and one audio track (typically AAC or MP3) per stream. Delivering multilingual broadcasts traditionally required running multiple encoder instances or pushing separate RTMP streams to distinct stream keys, consuming excessive bandwidth and processing power.

Enhanced RTMP solves this by introducing multi-track signaling, advanced codecs (such as AV1, HEVC, and Opus), and structured audio metadata within the standard RTMP chunk streaming protocol.

Audio Configuration and Independent Encoding

In OBS Studio, multi-track transmission begins in the output and audio routing settings:

  1. Source Routing: Using the Advanced Audio Properties matrix, sources (microphones, game audio, desktop sounds, or translated feeds) are assigned to distinct tracks (Tracks 1 through 6).
  2. Track Assignment: Each track is mapped to a specific language pair or audio role (for example, Track 1 for primary game sound and English commentary, Track 2 for Spanish commentary, Track 3 for clean ambient sound).
  3. Independent Encoding: OBS Studio’s audio pipeline sends each enabled track to its own audio encoder instance. Each track is compressed independently according to user configuration—typically using AAC or Opus—at its designated bitrate and sample rate.

Track Identification and Metadata Tagging

Once the audio frames are encoded, OBS Studio formats them to comply with the Enhanced RTMP multitrack standard:

  • Audio Message Extensions: Rather than utilizing legacy audio tags, OBS encapsulates compressed packets using updated header extensions.
  • Track IDs: Each audio packet is assigned a unique numerical TrackID. This ensures that audio data destined for one language track remains isolated from another.
  • Language and Metadata Signaling: Before streaming frames, or within regular metadata bursts, OBS sends an enhanced onMetaData or specific configuration message. This metadata maps each TrackID to standard language codes (such as ISO 639-1 or 639-2 codes like eng, spa, or jpn), channel layouts (e.g., stereo, 5.1), and descriptor strings.

Multiplexing Over a Single RTMP Stream

After encoding and tagging, OBS Studio multiplexes the video and all audio tracks into a unified byte stream:

  • Chunking: The RTMP protocol divides continuous media streams into chunks with specific chunk stream IDs (CSIDs).
  • Interleaving: Video chunks and audio chunks from Track 1, Track 2, and beyond are interleaved sequentially according to their presentation timestamps (PTS).
  • Single Socket Transmission: The interleaved data is pushed across a single TCP socket connection to the ingest server. Despite carrying multiple discrete language feeds, the network overhead remains minimal because there is no duplication of the video payload or transport headers.

Server Ingest and Client Separation

When the Enhanced RTMP-compatible ingest server receives the stream:

  1. It parses the incoming packet headers and reads the metadata identifying the available audio tracks and their assigned language codes.
  2. The server demultiplexes the tracks while preserving time synchronization relative to the primary video stream.
  3. The server then repackages the stream into modern egress formats (such as HLS, DASH, or WebRTC). In these output formats, the audio tracks appear as selectable alternative audio streams, allowing the end viewer's player to switch between languages seamlessly on demand.
