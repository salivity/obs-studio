OBS Studio DeckLink Multi-Monitor Video Output

This article explains how to configure OBS Studio and Blackmagic Design DeckLink hardware to route separate, discrete video feeds to multiple auxiliary monitors or external displays. Achieving independent auxiliary outputs requires configuring DeckLink SDI/HDMI ports for playback, setting up output filters or dedicated OBS tools per channel, and mapping individual scenes or sources to specific hardware outputs.

Prerequisites and Hardware Preparation

To send independent video feeds from a single computer running OBS Studio, you need a multi-channel DeckLink capture and playback card, such as the DeckLink Duo 2 (up to 4 channels) or DeckLink Quad 2 (up to 8 channels).

  1. Install Drivers: Download and install the latest Blackmagic Desktop Video software.
  2. Configure Port Mapping: Open the Blackmagic Desktop Video Setup utility. By default, multi-channel cards often share SDI connectors. Group or un-map connector pairs (e.g., mapping SDI 1 and SDI 2 as independent full-duplex or playback-only ports) to ensure each physical port acts as a standalone output channel.
  3. Format Alignment: Match the reference clock, frame rate, and resolution of each output port to the OBS Studio project settings (e.g., 1080p at 59.94 fps) to prevent conversion latency or frame tearing.

Native DeckLink Output in OBS Studio

OBS Studio includes native DeckLink output capability accessible via Tools > DeckLink Output.

  • Mode Selection: This tool allows you to assign a DeckLink hardware device to output either the Program feed or the Preview feed.
  • Limitations: The native tool natively controls only one hardware output channel at a time. It cannot route arbitrary, separate scenes to three or four physical DeckLink outputs simultaneously on its own.

Routing Discrete Feeds Using Filters and Plugins

To route distinct video sources—such as a dedicated confidence monitor, a clean camera feed, and a presenter timer—to separate DeckLink ports, you must use auxiliary tools or source-level filters.

Method 1: The DeckLink Source Output Plugin

Third-party plugins, such as the DeckLink Source Output filter (built on the DeckLink SDK), provide source-level hardware assignment.

  1. Install the compatible plugin into your OBS Studio plugin directory.
  2. Right-click the specific Scene or Source you want to route (e.g., "Stage Display").
  3. Select Filters, click the + (Add) icon under Audio/Video Filters, and select DeckLink Output.
  4. In the filter settings, select the target DeckLink device port (e.g., DeckLink Duo (2)).
  5. Choose the output format (e.g., 1080p59.94) and click Start.
  6. Repeat this process on other distinct sources or scenes, assigning each to a different physical DeckLink port (DeckLink Duo (3), DeckLink Duo (4), etc.).

Method 2: OBS Windowed / Fullscreen Projectors

If using DeckLink devices configured with WDM drivers or HDMI/DisplayPort auxiliary adapters that appear directly as OS-level displays:

  1. Right-click the desired Scene or Source inside the OBS interface.
  2. Hover over Fullscreen Projector (Source) or Windowed Projector (Source).
  3. Choose the auxiliary monitor linked to your hardware output.
  4. Each projection runs as an isolated thread, enabling simultaneous, unique feeds across every connected monitor.

Key Considerations for Stable Playback

  • PCIe Bandwidth: Ensure your DeckLink card is seated in a PCIe slot with adequate lanes (typically PCIe 2.0/3.0 x4 or x8) to handle simultaneous uncompressed video streams.
  • Color Space and Conversion: Match the OBS Canvas color format (NV12, P010, or I420) to the DeckLink output setting (usually YUV 4:2:2 8-bit or 10-bit) to minimize GPU color space conversion overhead.
  • Audio Routing: When assigning feeds, verify that audio monitoring settings in the Advanced Audio Properties are routed to the matching DeckLink channels if embedded SDI/HDMI audio is required on the auxiliary monitors.
