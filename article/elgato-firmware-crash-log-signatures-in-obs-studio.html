Elgato Firmware Crash Log Signatures in OBS Studio

When an Elgato capture card suffers a firmware or hardware-level crash while running OBS Studio, it suddenly stops delivering frames or disconnects from the system bus entirely. Identifying this issue requires inspecting the OBS Studio log file (Help > Log Files > View Current Log) for specific DirectShow, Windows Media Foundation, USB bus drop, or driver-level error signatures. This guide outlines the exact error codes and message patterns that indicate an Elgato capture card has crashed at the firmware level rather than experiencing a standard software configuration issue.

1. The DirectShow "Device Not Functioning" Failure (0x8007001F)

When the card's firmware hangs or the onboard processor resets, Windows reports a generic device failure. In OBS, the DirectShow video input subsystem logs an unrecoverable run failure:

[DShow Device: 'Elgato Capture Device'] Run failed (0x8007001F): A device attached to the system is not functioning.

This error (Win32 error code ERROR_GEN_FAILURE) means the operating system lost communication with the internal controller of the card mid-stream, pointing directly to a hardware or firmware freeze.

2. Sudden Device Removal and USB Bus Resets

A severe firmware crash will cause the card's USB controller to restart, triggering a hardware disconnect event in the log. Elgato devices share the Corsair/Elgato Vendor ID 0fd9:

User added source 'Video Capture Device' (dshow_input) to scene 'Live'
[DShow Device: 'Game Capture 4K60 S+'] Device disconnected
DShow: Device removed: \\?\usb#vid_0fd9&pid_...

If this disconnect happens without user intervention and is immediately followed by reconnection attempts or failed instantiation, the device underwent a hard firmware reboot.

3. Capture Graph Failure (E_FAIL / 0x80004005)

When the firmware freezes, the video stream halts abruptly, causing the media graph to fail when attempting to pull subsequent frames:

[DShow Device: 'Elgato HD60 X'] capture failed: 0x80004005
[DShow Device: 'Elgato HD60 X'] Video capture device is not providing frames

The error 0x80004005 (Unspecified Error / E_FAIL) coupled with the warning that the capture device has ceased providing frames indicates that the card remains recognized as an active USB endpoint by Windows, but its video encoding or HDMI processing block has crashed internally.

4. DirectShow Run Failure: Insufficient Resources (0x800705AA)

A firmware memory leak or buffer allocation crash on the device board will often manifest as:

[DShow Device: 'Elgato Game Capture HD60 S'] Run failed (0x800705AA): Insufficient system resources exist to complete the requested service.

Despite the wording, this error typically reflects exhausted onboard endpoint buffers or a stalled USB transfer descriptor on the device side, not an exhausted PC system RAM pool.

5. Simultaneous WASAPI Audio Termination

Elgato capture cards stream both video and audio over integrated DirectShow and WASAPI audio endpoints. If the firmware crashes, the audio engine drops at the exact same millisecond:

WASAPI: Device 'Game Capture HD60 X Audio' disconnected
WASAPI: Device 'Game Capture HD60 X Audio' invalidated

When paired with any of the DShow run failures above, this confirms that the entire hardware module lost power or reset, rather than an isolated video pipeline issue inside OBS Studio.
