How to Use and Export OBS Studio Scene Collections

In OBS Studio, managing different streaming and recording layouts can be challenging. This article explains what a scene collection is, how it helps organize your broadcasts, and provides a straightforward, step-by-step guide on how to export your collections to back them up or transfer them to another computer.

What is a Scene Collection in OBS Studio?

A scene collection in OBS Studio is a saved configuration of all your scenes and the sources within them. Think of it as a template or a profile for your visual layout. Instead of manually deleting and rebuilding your sources every time you want to switch from a gaming stream to a professional webinar, you can save each setup as its own scene collection.

Switching between collections instantly changes your entire OBS workspace to the pre-configured layout, including your overlays, camera positions, game captures, and browser sources.

How to Export a Scene Collection

Exporting a scene collection allows you to back up your hard work or move your layouts to a different computer. The process generates a lightweight .json file containing the configuration data.

Here is how to export your scene collection:

  1. Open OBS Studio.
  2. Click on Scene Collection in the top menu bar.
  3. Select the collection you want to export from the dropdown list to make it active.
  4. Click on Scene Collection in the menu bar again, then click Export.
  5. A file explorer window will open. Choose where you want to save the backup file on your computer.
  6. Name the file and click Save.

Note: The exported .json file only contains the layout data and settings. It does not package your actual media files (like images, videos, or audio files). If you import this collection on another computer, you must also transfer those media files and update their file paths in OBS.

How to Import a Scene Collection

If you need to load your saved layout back into OBS Studio or set it up on a new machine, follow these steps:

  1. Click on Scene Collection in the top menu bar.
  2. Select Import.
  3. Click the three dots (ellipsis) next to the "Collection Path" box to browse your files.
  4. Locate and select your exported .json file, then click Open.
  5. Click the Import button.
  6. To activate the imported layout, click on Scene Collection in the top menu and select your newly imported collection from the list.
