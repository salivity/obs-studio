How to Install StreamFX in OBS Studio

This guide provides a straightforward, step-by-step walkthrough on how to install the StreamFX plugin repository for OBS Studio. By following these instructions, you will gain access to advanced visual tools—such as custom shaders, professional blur filters, 3D transforms, and source mirrors—to significantly upgrade the production value of your live streams and recordings.

Step 1: Verify System Requirements and OBS Version

Before installing StreamFX, ensure your setup is compatible to prevent crashes:

  • OBS Studio Version: StreamFX requires specific versions of OBS Studio. Ensure your OBS Studio is updated to the latest stable release.
  • Graphics Drivers: Ensure your NVIDIA, AMD, or Intel graphics drivers are fully updated, as StreamFX heavily utilizes GPU-based shaders.

Step 2: Download the StreamFX Plugin

  1. Open your web browser and navigate to the official StreamFX GitHub Releases page or the official StreamFX website.
  2. Locate the latest stable release compatible with your version of OBS Studio.
  3. Download the appropriate installer for your operating system:
    • Windows: Download the .exe installer (recommended for automatic installation) or the .zip archive.
    • MacOS / Linux: Download the corresponding .pkg or .deb package.

Step 3: Install the StreamFX Plugin

Ensure that OBS Studio is completely closed before proceeding with the installation.

Method A: Using the Windows Installer (Recommended)

  1. Double-click the downloaded .exe installer file.
  2. If Windows Defender SmartScreen appears, click More Info and then Run anyway.
  3. Select the installation scope (either "Install for me only" or "Install for all users").
  4. Follow the on-screen prompts. The installer will automatically locate your OBS Studio installation directory and place the files in the correct folders.
  5. Click Finish once the installation is complete.

Method B: Manual Installation (Zip File)

  1. Extract the contents of the downloaded StreamFX .zip file.
  2. Locate your OBS Studio installation folder (usually C:\Program Files\obs-studio\).
  3. Copy the obs-plugins and data folders from the extracted StreamFX directory and paste them directly into your main obs-studio directory. Merge and overwrite any files if prompted.

Step 4: Verify the Installation in OBS Studio

  1. Launch OBS Studio.
  2. Look at the top menu bar. You should now see a new menu dropdown labeled StreamFX.
  3. To test the new filters, right-click any Source (such as a camera or capture card) in your Sources dock, select Filters, and click the + (plus) icon under Effect Filters.
  4. You should now see advanced options like Blur, 3D Transform, and Shader available in the list.
