Switch OBS Scene Collection via WebSocket Payload

Controlling OBS Studio remotely via its WebSocket interface requires sending formatted JSON messages to trigger internal functions. This article provides the exact JSON payload structure required to switch scene collections using the modern OBS WebSocket protocol (v5.x, built into OBS Studio 28 and later), along with an explanation of each field and the expected server response.

The Request Payload

To switch the active scene collection, you must send an OpCode 6 (Request) message containing the SetCurrentSceneCollection request type.

Here is the exact JSON payload:

{
  "op": 6,
  "d": {
    "requestType": "SetCurrentSceneCollection",
    "requestId": "f83a42d1-9b12-4c28-bb88-3482a939fef0",
    "requestData": {
      "sceneCollectionName": "Your Scene Collection Name"
    }
  }
}

Field Definitions

  • op (integer, required): Represents the WebSocket Operation Code. Setting this to 6 designates the message as a client-initiated Request.
  • d (object, required): The data envelope for the operation.
    • requestType (string, required): Must be exactly "SetCurrentSceneCollection".
    • requestId (string, required): An arbitrary, unique identifier generated by your client (such as a UUID). The OBS WebSocket server mirrors this identifier in its response so your application can correlate requests with responses.
    • requestData (object, required): Contains the parameters for the request.
      • sceneCollectionName (string, required): The exact, case-sensitive name of the scene collection you want to activate in OBS Studio.

Expected Server Response

If the scene collection exists and switches successfully, the OBS WebSocket server will respond with an OpCode 7 (RequestResponse) message:

{
  "op": 7,
  "d": {
    "requestType": "SetCurrentSceneCollection",
    "requestId": "f83a42d1-9b12-4c28-bb88-3482a939fef0",
    "requestStatus": {
      "result": true,
      "code": 100
    }
  }
}
  • requestStatus.result: Returns true on success and false if the collection name was not found or failed to load.
  • requestStatus.code: Status code 100 signifies a generic success. If the requested scene collection does not exist, the server returns an error code (such as 600 for resource not found).

Important Considerations

  • Switching scene collections causes OBS Studio to unload all current assets, sources, and filters before loading the new collection. This operation is blocking and may take several seconds depending on the complexity of your scenes and hardware performance.
  • While the switch is occurring, the WebSocket connection may pause message processing until the new scene collection is fully initialized.
