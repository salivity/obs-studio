Create a Web Tally Light Dock in OBS Studio

Setting up a custom web-based tally light dock within OBS Studio allows operators to monitor live and preview states directly inside the native interface. This guide covers how to enable the built-in OBS WebSocket server, configure a web tally page, and embed it as a functional, dockable panel in the OBS Studio workspace.

1. Enable the OBS WebSocket Server

Modern versions of OBS Studio (version 28 and above) include native WebSocket support, which enables external web interfaces to read the status of scenes and outputs.

  1. Open OBS Studio.
  2. Navigate to Tools > WebSocket Server Settings.
  3. Check the box labeled Enable WebSocket server.
  4. Note the Server Port (the default is 4455).
  5. Click Generate Password or set a custom password, then click Apply and OK. Keep this password handy, as the web tally interface will need it to connect.

2. Set Up the Web Tally Interface

You need a web application capable of communicating with the OBS WebSocket protocol to display tally states (typically red for Program/Live and green for Preview).

  • Pre-built Solutions: Tools like Tally Arbiter, OBS-web, or dedicated web tally pages can be hosted locally via Node.js/Docker or accessed via hosted web services.
  • Custom HTML/JavaScript: Alternatively, you can build a lightweight local HTML page utilizing the obs-websocket-js library. The script connects to ws://localhost:4455, authenticates using your password, and listens for the CurrentProgramSceneChanged and CurrentPreviewSceneChanged events to toggle background colors on the page.

Ensure the web application is running and accessible via a standard URL (for example, http://localhost:8080 or a remote HTTPS address).

3. Add the Custom Browser Dock

Once the web tally page is functioning, integrate it directly into the OBS interface:

  1. In the top OBS menu bar, go to Docks > Custom Browser Docks....
  2. Under the Dock Name column, enter a name (e.g., Live Tally).
  3. Under the URL column, paste the web address of your tally application. Include any necessary URL parameters if your tally tool supports auto-login (such as ?address=localhost&port=4455&pwd=YOUR_PASSWORD).
  4. Click Apply, then click Close.

4. Dock and Test the Interface

  1. The newly created tally dock will appear as a floating window over your OBS interface.
  2. Authenticate the page if credentials were not passed in the URL.
  3. Click and drag the title bar of the tally window toward any edge or existing dock in OBS (such as above the Preview window or next to the Audio Mixer) until a blue highlight indicates where it will dock.
  4. Release the mouse button to snap it into place.
  5. Switch scenes, enter Studio Mode, or transition between Preview and Program to verify that the tally colors update accurately in real time.
