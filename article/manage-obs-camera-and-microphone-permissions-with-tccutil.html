Manage OBS Camera and Microphone Permissions with tccutil

macOS relies on the Transparency, Consent, and Control (TCC) framework to protect user privacy by restricting application access to sensitive hardware. The command-line utility tccutil interacts directly with this system to manage access rights for applications like OBS Studio. This guide covers the specific permission strings managed by tccutil, how the utility functions regarding camera and microphone access, and the exact steps required to configure OBS Studio properly.

Specific TCC Service Names

To manage hardware access for OBS Studio through the TCC framework, macOS defines distinct service identifiers. The specific permissions are:

  • Camera: Camera
  • Microphone: Microphone

The bundle identifier for OBS Studio required to target the application specifically is:

  • com.obsproject.obs-studio

Understanding the Limitations of tccutil

A critical security aspect of macOS is that tccutil cannot directly grant permissions from the command line. Allowing the command line to grant permissions arbitrarily would enable malicious scripts to bypass user consent.

Instead, tccutil is strictly designed to reset permissions. Resetting the permission clears the current state (whether granted or denied), forcing macOS to prompt the user for permission again the next time the application requests access.

How to Reset OBS Studio Permissions Using tccutil

If OBS Studio is not capturing video or audio, or if permission was previously denied, you can clear the permission state using Terminal.

Reset Camera Permission

To reset camera access specifically for OBS Studio, execute:

tccutil reset Camera com.obsproject.obs-studio

Reset Microphone Permission

To reset microphone access specifically for OBS Studio, execute:

tccutil reset Microphone com.obsproject.obs-studio

Reset System-Wide Camera and Microphone Permissions

If you omit the bundle identifier, the command resets the permission for every application on the system:

tccutil reset Camera
tccutil reset Microphone

How to Grant Permissions to OBS Studio

Because tccutil cannot directly grant access, use one of the following methods to authorize OBS Studio:

1. The Standard Application Prompt

  1. Run the reset commands via tccutil for both Camera and Microphone.
  2. Launch OBS Studio.
  3. Add a Video Capture Device and an Audio Input Capture source to your scene.
  4. When macOS displays the system prompt requesting permission for the camera and microphone, click OK.

2. Manual Configuration via System Settings

If prompts do not appear, you must manually toggle access:

  1. Open System Settings on macOS.
  2. Navigate to Privacy & Security.
  3. Select Camera, locate OBS, and toggle the switch to the On position.
  4. Return to Privacy & Security, select Microphone, locate OBS, and toggle the switch to the On position.
  5. Restart OBS Studio for the changes to take effect.
