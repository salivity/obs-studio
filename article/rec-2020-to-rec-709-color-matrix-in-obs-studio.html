Rec 2020 to Rec 709 Color Matrix in OBS Studio

This article provides the exact 3x3 color conversion matrix implemented by OBS Studio to map Rec. 2020 HDR color primaries into Rec. 709 SDR color space. It outlines the precise floating-point coefficients utilized in OBS Studio's internal graphics shaders, explains the mathematical derivation based on standard CIE colorimetry, and details where this operation occurs within the HDR-to-SDR tone-mapping pipeline.

The Conversion Matrix

OBS Studio performs primary conversions in linear light space. When converting linear Rec. 2020 coordinates \([R_{2020}, G_{2020}, B_{2020}]^T\) to linear Rec. 709 coordinates \([R_{709}, G_{709}, B_{709}]^T\), the following 3×3 matrix is applied:

$$ \begin{bmatrix} R_{709} \ G_{709} \ B_{709} \end{bmatrix}

\begin{bmatrix} 1.660491 & -0.587641 & -0.072850 \ -0.124550 & 1.132855 & -0.008305 \ -0.018151 & -0.100579 & 1.118730 \end{bmatrix} \begin{bmatrix} R_{2020} \ G_{2020} \ B_{2020} \end{bmatrix} $$

In OBS Studio's internal HLSL shader pipeline (specifically within the color-processing rendering passes), this is implemented as:

static const float3x3 rec2020_to_rec709 = {
    1.660491, -0.587641, -0.072850,
   -0.124550,  1.132855, -0.008305,
   -0.018151, -0.100579,  1.118730
};

Derivation from CIE 1931 Primaries

Because both ITU-R BT.2020 and ITU-R BT.709 share the identical CIE Standard Illuminant D65 white point (\(x_n = 0.3127, y_n = 0.3290\)), no chromatic adaptation transform (such as Bradford or Von Kries) is required.

The matrix is calculated by computing the normalized primary matrix for each color space relative to CIE 1931 \(XYZ\):

  1. Rec. 709 Primaries:

    • Red: \((0.64, 0.33)\)
    • Green: \((0.30, 0.60)\)
    • Blue: \((0.15, 0.06)\)

  2. Rec. 2020 Primaries:

    • Red: \((0.708, 0.292)\)
    • Green: \((0.170, 0.797)\)
    • Blue: \((0.131, 0.046)\)

Multiplying the inverse of the Rec. 709 RGB-to-XYZ matrix by the Rec. 2020 RGB-to-XYZ matrix produces the direct linear transformation:

\[M_{2020 \to 709} = M_{709 \to XYZ}^{-1} \times M_{2020 \to XYZ}\]

Processing Order in the OBS Pipeline

The matrix is not applied directly to non-linear video frames. OBS Studio applies this conversion within a strict color pipeline:

  1. YUV to Non-Linear RGB: The incoming video feed (commonly 10-bit YUV 4:2:0 using BT.2020 non-constant luminance) is converted to non-linear \(R'G'B'_{2020}\).
  2. Electro-Optical Transfer Function (EOTF): Non-linear values are linearized using either the SMPTE ST 2084 (PQ) or ARIB STD-B67 (HLG) transfer function.
  3. Primary Transformation: The linear color vectors are multiplied by the rec2020_to_rec709 matrix.
  4. Tone Mapping and Gamut Mapping: Because Rec. 2020 contains colors outside the physical gamut of Rec. 709, negative values and out-of-range highlights are mapped, compressed, or clipped according to the selected SDR tone-mapping operator (such as Reinhard or Aces Filmic).
  5. Opto-Electronic Transfer Function (OETF): The mapped linear values are encoded into standard Rec. 709 gamma (typically power 2.2 or ITU-R BT.709/sRGB curve) for SDR presentation and recording.
