OBS Studio 16:9 to 21:9 Scene Layout Migration

Migrating OBS Studio scene collections between 16:9 and 21:9 aspect ratios requires an understanding of how the software handles coordinates, canvas boundaries, and source transformations. By default, OBS Studio does not dynamically reflow or auto-scale layouts when the Base (Canvas) Resolution changes. Instead, it relies on an absolute coordinate system and user-defined bounding box constraints to maintain element proportions and positions across different display formats.

The Absolute Coordinate System

OBS Studio maps all visual elements using an absolute pixel-based grid starting from an origin point—typically the top-left corner (coordinates 0, 0). When you change your canvas resolution from 16:9 (such as 1920×1080) to an ultrawide 21:9 format (such as 2560×1080 or 3440×1440), the existing assets remain anchored to their absolute pixel coordinates.

Because the canvas width expands horizontally while the vertical bounds remain proportionally identical, your existing elements will not automatically stretch or reposition toward the center. Instead, the extra horizontal canvas space appears on the right and bottom edges, leaving the original 16:9 layout grouped toward the top-left unless repositioned.

Role of Bounding Box Types in Aspect Ratio Preservation

To prevent visual distortion when switching resolutions, OBS Studio relies on "Bounding Box" settings assigned to each source. These settings dictate how an image, browser capture, or video feed reacts when its container size changes:

  • No Bounds (Default): The source displays at its native resolution or manually dragged dimensions. Changing the scene canvas does not alter the size of the source, but it may cause the source to be cut off or positioned awkwardly relative to the new borders.
  • Scale to Inner / Outer Bounds: These modes enforce an aspect-ratio lock. If a bounding box is set up within a scene, the asset retains its correct proportion within that box regardless of global canvas adjustments, preventing unnatural horizontal stretching.
  • Fit to Screen: Pressing Ctrl + F scales the selected source to fit within the new bounds while strictly preserving its original aspect ratio, automatically introducing pillarboxing (black bars on the sides) on a 21:9 canvas for 16:9 media.
  • Stretch to Screen: Pressing Ctrl + S forces the element to cover the entire canvas. This breaks aspect ratio proportions, distorting 16:9 sources across a 21:9 space, and is generally avoided during migration.

Maintaining Layouts via Nested Scenes

The most robust technique OBS Studio uses to maintain a composite layout's exact proportions across different aspect ratios is scene nesting.

Instead of moving individual sources directly into an ultrawide canvas, an entire 16:9 scene can be imported as a single source into a 21:9 scene collection. Within this parent scene:

  1. The 16:9 layout remains fully intact as a self-contained sub-canvas.
  2. The sub-canvas can be centered, anchored, or scaled uniformly without misaligning individual elements like overlays, webcams, and chat boxes.
  3. The remaining flanking areas (the extra 21:9 horizontal space) can then be populated with dedicated side panels, stream alerts, or extended game viewports.

Transform Alignment Anchors

OBS uses positional alignment anchors (found in the "Edit Transform" menu) to govern how sources anchor relative to their positions. By switching an alignment point from "Top Left" to "Center," sources react more predictably to global coordinate adjustments. While this does not automatically resize assets to fit ultrawide dimensions, it keeps central elements centered on the screen when changing canvas dimensions manually.
