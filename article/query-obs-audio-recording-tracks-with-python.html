Query OBS Audio Recording Tracks with Python

An external Python automation script interacts with OBS Studio by communicating over the native OBS WebSocket API to inspect configuration settings and audio routing. By utilizing a WebSocket client library like obsws-python, the script authenticates with OBS, queries the active output configuration to determine which recording tracks (1 through 6) are enabled, and retrieves track-routing maps for individual audio sources.

Prerequisites and Setup

OBS Studio (version 28 and later) includes built-in WebSocket support. To allow an external script to connect:

  1. Open OBS Studio and navigate to Tools > WebSocket Server Settings.
  2. Check Enable WebSocket server.
  3. Note the Server Port (default is 4455) and set a Server Password.

Install the modern OBS WebSocket v5 Python client:

pip install obsws-python

Understanding OBS Audio Tracks

OBS Studio supports up to 6 distinct audio tracks. Querying "available audio recording tracks" generally involves two aspects:

  1. Active Recording Output Tracks: Which of the 6 tracks are actively set to be recorded to the output file.
  2. Source Track Routing: Which tracks are currently assigned to receive audio from specific inputs (e.g., microphones or desktop audio).

Querying Configured Recording Tracks

To check which tracks are enabled for recording, query the active profile configuration via the GetProfileParameter request. In advanced output mode, OBS stores selected recording tracks as a bitmask or string in the AdvOut category under RecTracks.

import obsws_python as obs

# Connect to the OBS WebSocket server
client = obs.ReqClient(host="localhost", port=4455, password="your_password")

# Retrieve the record track bitmask from the active profile
response = client.get_profile_parameter(
    parameter_category="AdvOut",
    parameter_name="RecTracks"
)

track_bitmask = int(response.parameter_value)

# Determine which tracks (1-6) are toggled on
enabled_tracks = [track for track in range(1, 7) if track_bitmask & (1 << (track - 1))]

print(f"Enabled recording tracks: {enabled_tracks}")

Querying Audio Track Assignments per Input

To query which of the 6 tracks a specific audio source is routed to, use the GetInputAudioTracks request:

import obsws_python as obs

client = obs.ReqClient(host="localhost", port=4455, password="your_password")

# Fetch all available input sources
inputs = client.get_input_list().inputs

for item in inputs:
    input_name = item["inputName"]
    input_kind = item["inputKind"]

    # Filter out sources that do not process audio
    try:
        track_data = client.get_input_audio_tracks(name=input_name)
        active_tracks = [
            track for track, is_active in track_data.input_audio_tracks.items() if is_active
        ]
        print(f"Source: '{input_name}' ({input_kind}) -> Routed to Tracks: {active_tracks}")
    except obs.error.OBSSDKError:
        # Source does not support audio tracks
        continue

Summary of the Flow

  1. Establish a WebSocket connection using obsws-python.ReqClient.
  2. Query the profile settings using GetProfileParameter to identify which global tracks (1 to 6) write to the output container.
  3. Query input sources using GetInputAudioTracks to inspect the audio channel routing for each individual device or application capture inside OBS.
