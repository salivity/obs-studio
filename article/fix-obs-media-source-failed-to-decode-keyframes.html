Fix OBS Media Source Failed to Decode Keyframes

When OBS Studio reports that a media source failed to decode keyframes in its log files, it typically points to video corruption, an unsupported codec profile, hardware acceleration failure, or an irregular Group of Pictures (GOP) structure. This error causes visual stuttering, frozen video frames, or a persistent black screen in your scene. The following diagnostic steps will help you isolate the root cause, repair the media source, and restore stable playback within OBS Studio.

1. Toggle Hardware Decoding in Media Source Properties

Hardware-accelerated decoding depends on your GPU's dedicated decoders (such as NVDEC, Intel QuickSync, or AMD AMF). If the media file uses a profile or pixel format unsupported by your GPU driver, the decoder will fail to parse incoming keyframes (I-frames).

  • Open OBS Studio and locate the problematic source in your Sources list.
  • Double-click the source to open its Properties.
  • Look for the option labeled Apply hardware decoding when available.
  • If it is checked, uncheck it to force OBS Studio's internal FFmpeg software decoder to process the frames.
  • If it is already unchecked, check it to determine if your hardware decoder can process the stream instead of CPU-based decoding.
  • Click OK, restart the playback, and check the OBS log (Help > Log Files > View Current Log) to see if the keyframe decode error persists.

2. Inspect the Video Codec and Keyframe Interval

Files recorded with Variable Frame Rates (VFR) or unusually long keyframe intervals (GOP sizes exceeding several seconds) can trigger decode timeouts in OBS.

  • Use a diagnostic utility such as MediaInfo to inspect the file's video stream.
  • Check the Format Profile and Frame Rate Mode. If the frame rate mode is variable, or if the video uses atypical profiles (such as 10-bit H.264 High 10 or 4:4:4 chroma subsampling), OBS’s native media source demuxer may struggle to parse keyframes reliably.
  • Verify that the file uses standard Constant Frame Rate (CFR) video with 4:2:0 chroma subsampling (YUV420P) and 8-bit color depth.

3. Re-Encode the Media File

Re-encoding the file into a standardized, production-ready format resolves missing header data, broken index tables, and non-standard keyframe intervals.

  • Open an encoder like HandBrake, Avidemux, or use an FFmpeg command.
  • Set the video encoder to standard H.264 (x264).
  • Set the framerate to Constant Framerate (CFR).
  • Explicitly define a keyframe interval (GOP size) of 1 to 2 seconds. In HandBrake, this is managed via the Keyframe Interval field; in FFmpeg, pass -g 60 (for 30 FPS content) or -g 120 (for 60 FPS content).
  • Save the output as a standard .mp4 container and replace the old asset inside OBS Studio.

4. Switch to the VLC Video Source Alternative

OBS Studio features an alternative video playback engine via the VLC Video Source plugin, which uses VLC's native demuxers rather than the standard OBS FFmpeg implementation.

  • Ensure you have the 64-bit version of VLC Media Player installed on your operating system.
  • In OBS Studio, click the + (Add) button in the Sources dock.
  • Select VLC Video Source. If the option is absent, reinstall the 64-bit release of VLC and restart OBS.
  • Add your media file to the playlist inside the VLC Video Source properties.
  • Test playback. VLC handles malformed keyframes, non-standard containers, and network-streamed media with greater fault tolerance than the default Media Source.

5. Check Disk I/O and File Location

A file that cannot read fast enough off storage can drop packets and fail keyframe reconstruction, especially with high-bitrate video clips (such as ProRes or lossless AVI).

  • Move the video file to a local, high-speed solid-state drive (SSD).
  • Avoid sourcing active media files directly from network-attached storage (NAS), cloud-synced folders (OneDrive, Google Drive), or low-power external USB drives that may sleep or throttle read speeds.

6. Update or Clean-Install Graphics Drivers

If software decoding functions properly but hardware decoding continuously fails on keyframes, your graphics driver's media pipeline may be corrupted or out of date.

  • Download the latest driver release directly from your GPU manufacturer (NVIDIA, AMD, or Intel).
  • Perform a clean installation of the driver to reset the hardware video decoding configurations.
  • Restart your PC and re-enable hardware decoding inside OBS Studio to verify the fix.
