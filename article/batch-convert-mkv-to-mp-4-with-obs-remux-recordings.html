Batch Convert MKV to MP4 with OBS Remux Recordings

OBS Studio records in the MKV format by default to prevent file corruption in the event of a crash, but many video editors and media players require MP4 or MOV files. This guide provides a straightforward, step-by-step walkthrough on how to use OBS Studio's built-in "Remux Recordings" tool to batch-convert multiple MKV files into MP4 format simultaneously without losing any video quality.

Step 1: Open the Remux Recordings Tool

  1. Launch OBS Studio on your computer.
  2. Click on File in the top-left corner of the menu bar.
  3. Select Remux Recordings from the dropdown menu. This will open a new window.

Step 2: Import Multiple MKV Files

You can add multiple files to the Remux window at the same time using one of two methods:

  • Drag and Drop: Open your file explorer, select all the MKV files you wish to convert, and drag them directly into the "Remux Recordings" window.
  • Manual Selection: Click the three dots (...) under the OBS Recording column, select your MKV files, and click Open. Repeat this for each file you want to add to the list.

Step 3: Verify the Output Destination

Once your MKV files are imported, OBS Studio will automatically populate the Target File column.

  • By default, OBS set the output format to .mp4 and saves the new files in the same directory as the original MKV files.
  • If you want to change the output path or file name for a specific video, click the three dots (...) in the Target File column next to that video and choose a new location.

Step 4: Run the Batch Remux Process

  1. Look at the bottom right of the Remux window and click the Remux button.
  2. OBS Studio will process all the files in the list queue simultaneously. Because remuxing only changes the file container without re-encoding the video, this process takes only a few seconds per file.
  3. A dialog box will appear saying "Recording remuxed" once the process is finished. Click OK to close it.

You can now close the Remux window and find your newly created MP4 files ready for use in your video editing software.
