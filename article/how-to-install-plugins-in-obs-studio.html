How to Install Plugins in OBS Studio

Enhancing your live stream or video recording setup often requires extending the default capabilities of OBS Studio. This guide provides a straightforward, step-by-step walkthrough on how to install third-party plugins into OBS Studio for both Windows and macOS, covering both automatic installers and manual installation methods to help you easily unlock new features like advanced transitions, audio filters, and custom sources.

Method 1: Using an Automatic Installer (Recommended)

Many popular OBS plugins come with an executable installer that handles the setup process automatically. This is the easiest and safest method.

  1. Download the Plugin: Visit the official OBS Resources page or the developer's trusted website and download the installer file (usually an .exe file for Windows or a .pkg or .dmg file for macOS).
  2. Close OBS Studio: Ensure OBS Studio is completely closed before running the installer to prevent file conflicts.
  3. Run the Installer: Double-click the downloaded file and follow the on-screen prompts. The installer will automatically locate your OBS Studio directory and place the files in the correct folders.
  4. Restart OBS Studio: Open OBS Studio to verify that the plugin has been successfully integrated.

Method 2: Manual Installation (ZIP Files)

If the plugin does not have an automatic installer, it will download as a compressed ZIP folder. You will need to extract and place these files into the OBS directory manually.

On Windows:

  1. Download and Extract: Download the plugin's .zip file and extract its contents using Windows Explorer, WinRAR, or 7-Zip.
  2. Locate the Folders: Inside the extracted folder, you will typically see two folders: data and obs-plugins.
  3. Navigate to the OBS Directory: Open a new File Explorer window and go to your OBS Studio installation folder. By default, this is located at: C:\Program Files\obs-studio
  4. Copy and Merge: Copy the data and obs-plugins folders from the extracted ZIP file and paste them directly into the obs-studio directory. When prompted, select Yes to merge the folders and replace any existing files (administrator permission may be required).

On macOS:

  1. Download and Extract: Download and extract the plugin's .zip archive.
  2. Navigate to the Plugins Folder: Open Finder, press Cmd + Shift + G, and paste the following path: ~/Library/Application Support/obs-studio/plugins/ (If the plugins folder does not exist, create a new folder and name it plugins.)
  3. Copy the Files: Copy the extracted plugin files (usually ending in .plugin) and paste them directly into this directory.

How to Verify the Plugin is Working

Once installed, restart OBS Studio to load the new files. You can verify the plugin is active by checking the following areas:

  • Tools Menu: Click on Tools in the top menu bar; many utility plugins will list their settings here.
  • Sources List: Click the + (plus) icon under the Sources dock to see if new source types have been added.
  • Filters: Right-click on an audio or video source, select Filters, and click the + icon to see if new audio/video filters are available.
