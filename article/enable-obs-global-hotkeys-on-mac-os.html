Enable OBS Global Hotkeys on macOS

To use global hotkeys in OBS Studio while the application is minimized or running in the background on macOS, you must grant the app Accessibility permissions. macOS restricts background applications from monitoring system-wide keyboard events for security reasons, meaning OBS Studio cannot detect your shortcut presses unless explicitly authorized. This guide explains which permissions are required, why they are necessary, and how to configure them properly in your system settings.

The Required Permission: Accessibility

The primary permission required for OBS Studio to register global hotkeys while backgrounded is Accessibility.

In macOS, listening to keystrokes outside of an active application requires the use of global event taps (CGEventTap). Because this capability can potentially be exploited by malicious software to log keystrokes, macOS blocks background event monitoring by default. Granting Accessibility access explicitly authorizes OBS Studio to capture keyboard events even when another program is in focus.

In some recent macOS versions, Input Monitoring may also be requested or required depending on the specific input devices or advanced key capture methods being used. However, Accessibility remains the essential authorization for standard hotkey listeners.

How to Grant Hotkey Permissions to OBS Studio

Follow these steps to enable Accessibility permissions for OBS Studio on macOS Ventura, Sonoma, and later:

  1. Quit OBS Studio completely to ensure permissions apply correctly upon restart.
  2. Open System Settings on your Mac.
  3. Click Privacy & Security in the sidebar.
  4. Scroll down and select Accessibility on the right.
  5. Locate OBS in the list and toggle the switch to the On position.
    • If prompted, enter your Mac's administrator password or use Touch ID.
    • If OBS is not in the list, click the Add (+) button at the bottom of the list, navigate to your Applications folder, select OBS.app, and click Open.
  6. Relaunch OBS Studio.

Troubleshooting Hotkey Issues After Updates

If OBS Studio stops responding to background hotkeys after updating macOS or updating the OBS application itself, permissions can become desynchronized:

  • Toggle Permissions Off and On: Go back to System Settings > Privacy & Security > Accessibility, toggle the switch for OBS to Off, and then toggle it back to On.
  • Remove and Re-add: If toggling fails, select OBS in the Accessibility list, click the Remove (-) button, and manually re-add the application.
  • Check Input Monitoring: If hotkeys still do not trigger, navigate to System Settings > Privacy & Security > Input Monitoring and ensure OBS is added and enabled there as well.
