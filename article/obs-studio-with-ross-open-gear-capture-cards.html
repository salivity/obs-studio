OBS Studio with Ross openGear Capture Cards

This article explains how commercial television studios interface OBS Studio with Ross Video openGear modular infrastructure for streaming, monitoring, and auxiliary production. While openGear frames house broadcast-grade signal processing and routing cards, OBS Studio operates as an encoding and software-mixing layer. Integrating the two systems relies on converting openGear baseband or network streams into computer-ingestible protocols through physical capture hardware, IP transport layers, and centralized DashBoard control integration.

In a commercial broadcast facility, the openGear chassis serves as a centralized 2RU modular frame supplying redundant power, cooling, and network communication to up to 20 processing cards. Unlike consumer USB or PCIe capture cards installed directly into a host PC, openGear cards reside in an equipment rack and handle tasks like SDI distribution, frame synchronization, color correction, and scan conversion. Because openGear cards output broadcast standard signals rather than USB video class (UVC) feeds, an intermediate transport layer is required to bridge the frame to the host computer running OBS Studio.

The most common method to bring openGear video into OBS Studio is through intermediate baseband SDI ingest. The openGear frame routes processed 3G-SDI, 12G-SDI, or HDMI outputs directly into a dedicated workstation equipped with multi-channel PCIe capture cards, such as Blackmagic DeckLink or AJA KONA. OBS Studio accesses these feeds natively using the DeckLink Video Capture source or through standard DirectShow drivers. This configuration allows commercial facilities to utilize openGear's heavy-duty processing—such as up/down/cross-conversion and audio embedding—before delivering pristine, low-latency video into OBS Studio for secondary digital feeds, clean recording, or client review streams.

A growing number of broadcast facilities use IP-based conversion cards within the openGear chassis to bypass physical workstation capture cards entirely. Modular cards designed for the openGear ecosystem, including SDI-to-NDI or SMPTE ST 2110 gateway cards, encode baseband SDI feeds directly into network packets at the rack level. OBS Studio captures these streams over a 10GbE or 25GbE local production network using the obs-ndi plugin or native network media inputs (SRT, UDP, RTSP). This approach eliminates the distance limitations of SDI cables and allows multiple OBS instances on the facility network to ingest the same openGear card output simultaneously.

Control room automation ties the hardware and software layers together using Ross DashBoard, the open-architecture network control and management software for openGear. Broadcast engineers configure, monitor, and route the openGear cards via DashBoard CustomPanels. By leveraging DashBoard's network scripting alongside the OBS Studio WebSocket API or third-party broadcast automation tools, engineers can synchronize openGear signal routes with OBS scene changes, automated tallies, and stream start/stop commands, delivering a unified workflow in commercial broadcast environments.
