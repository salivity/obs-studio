Trigger OBS Scenes via Custom Browser URL Schemes

Configuring a custom URL scheme allows desktop web browsers to interact directly with OBS Studio, enabling you to switch scenes, toggle sources, or start recordings by clicking links on a webpage. This integration relies on registering a custom URI protocol within your operating system, which intercepts browser requests and routes them to an intermediary script that communicates with OBS Studio via its built-in WebSocket server.

Step 1: Enable the OBS WebSocket Server

OBS Studio (version 28 and above) includes a native WebSocket server required for receiving external API commands.

  1. Launch OBS Studio.
  2. Navigate to Tools in the top menu and select WebSocket Server Settings.
  3. Check Enable WebSocket server.
  4. Set the Server Port (default is 4455).
  5. (Optional) Set a password under Server Password to secure the connection, or leave it disabled for local automation.
  6. Click Apply and OK.

Step 2: Create the Handler Script

Browsers cannot open direct raw WebSocket connections to system software using a custom protocol without an application-level handler. A lightweight Python script can act as the bridge between your URL scheme and OBS.

  1. Install the OBS WebSocket client library:

    pip install obsws-python

  2. Create a script named obs_handler.py:

    import sys
from urllib.parse import urlparse, parse_qs
import obsws_python as obs

# Parse the custom URI passed by the OS (e.g., obs://switch-scene?name=Gameplay)
if len(sys.argv) < 2:
    sys.exit(1)

raw_url = sys.argv[1]
parsed = urlparse(raw_url)
action = parsed.netloc or parsed.path.strip("/")
params = parse_qs(parsed.query)

# Connect to OBS WebSocket
client = obs.ReqClient(host='localhost', port=4455, password='')

if action == "switch-scene":
    scene_name = params.get('name', [None])[0]
    if scene_name:
        client.set_current_program_scene(scene_name)

  3. Wrap this script into an executable or create a .bat file (e.g., run_obs_handler.bat) so the operating system can execute it cleanly:

    @echo off
python "C:\Path\To\obs_handler.py" %1

Step 3: Register the Custom URI Scheme in Windows

To allow your browser to recognize links starting with obs://, register the protocol in the Windows Registry.

  1. Open a text editor and paste the following configuration (replace C:\\Path\\To\\run_obs_handler.bat with your actual file path, escaping backslashes): 
    Windows Registry Editor Version 5.00

[HKEY_CLASSES_ROOT\obs]
@="URL:OBS Protocol"
"URL Protocol"=""

[HKEY_CLASSES_ROOT\obs\shell]

[HKEY_CLASSES_ROOT\obs\shell\open]

[HKEY_CLASSES_ROOT\obs\shell\open\command]
@="\"C:\\Path\\To\\run_obs_handler.bat\" \"%1\""
  2. Save the file as register_obs_scheme.reg.
  3. Double-click the .reg file and accept the prompt to apply the changes to your system registry.

(On macOS, create a minimal Automator Application configured as an "Application receives service" or edit the CFBundleURLTypes entry in an application's Info.plist file.)

Step 4: Trigger Actions from the Browser

Once registered, any standard HTML link or JavaScript redirect in your browser using the custom scheme will execute the command in OBS Studio.

  • HTML Anchor Link:

    <a href="obs://switch-scene?name=BRB">Switch to BRB Scene</a>

  • JavaScript Execution:

    function changeScene(sceneName) {
    window.location.href = `obs://switch-scene?name=${encodeURIComponent(sceneName)}`;
}

When clicked, the browser displays a one-time security prompt asking for permission to open the registered handler. Once allowed, the script passes the request to the OBS WebSocket server, instantly changing the scene.
