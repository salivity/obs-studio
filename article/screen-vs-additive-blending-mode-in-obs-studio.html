Screen vs Additive Blending Mode in OBS Studio

In OBS Studio, both the Screen and Additive blending modes are used to combine overlapping visual sources by making dark areas transparent and brightening the underlying scene. While both modes brighten the composite image and render pure black as fully transparent, they differ fundamentally in how they calculate pixel values: Additive mode directly sums color values together, often leading to blown-out white highlights, whereas Screen mode uses an inverted multiplication algorithm that preserves highlights and prevents harsh clipping.

The Mathematics Behind the Modes

The difference in visual output stems from the underlying formulas the OBS compositor uses to calculate the final pixel values (normalized on a scale from 0 to 1):

  • Additive Blending (Linear Dodge): \[\text{Result} = \text{Base} + \text{Blend}\] The RGB values of the source layer are added directly to the values of the layer beneath it. If the sum of any color channel exceeds 1.0 (or 255 in 8-bit color), it hard-clips at maximum brightness.
  • Screen Blending: \[\text{Result} = 1 - (1 - \text{Base}) \times (1 - \text{Blend})\] The compositor inverts both layers, multiplies them, and then inverts the result. Because multiplying fractions always produces a smaller fraction, the result can never exceed 1.0 unless one of the inputs is already at maximum brightness.

Visual Differences

1. Highlight Handling and Clipping

  • Additive: Rapidly pushes pixels to pure white (#FFFFFF). Overlapping two moderately bright elements will almost always result in an overexposed, blown-out area.
  • Screen: Compresses highlights smoothly. It produces a soft roll-off, meaning that even bright overlapping areas retain some color saturation and texture rather than clipping immediately to solid white.

2. Contrast and Color Saturation

  • Additive: Desaturates colors in bright areas because when red, green, and blue channels clip at maximum value simultaneously, the result is white.
  • Screen: Retains more of the original layer's hue and mid-tone contrast, resulting in a more natural photographic blend.

How Both Modes Handle Transparency

Both modes eliminate the need for an alpha channel when using assets rendered against a black background:

  • Adding 0 (black) to any color results in the original color, rendering black completely invisible.
  • Screening with 0 also leaves the base color completely unchanged.

When to Use Each in OBS Studio

Use Additive Blending When:

  • You want intense, high-energy visual effects such as laser beams, magic spells, neon glows, or explosions.
  • You are layering light sources where physical accumulation of light energy is desired (e.g., optical lens flare cores).
  • The asset is semi-transparent and needs maximum visibility against bright game capture backgrounds.

Use Screen Blending When:

  • You are overlaying atmospheric elements like smoke, fog, dust particles, or gentle rain.
  • You want to overlay webcam light leaks or cinematic film burns without obscuring the background footage completely.
  • You want to preserve the color fidelity and subtle textures of an overlay rather than washing it out into white.
