Register a Custom Transition in OBS Studio

External developers can register a custom transition type in OBS Studio by implementing a dedicated transition source using libobs. This process entails defining an obs_source_info structure configured with the OBS_SOURCE_TYPE_TRANSITION type flag, implementing the required lifecycle and rendering callbacks, and registering the definition during the plugin's obs_module_load initialization sequence.

Core Concepts of OBS Transitions

In OBS Studio, transitions are treated as a specialized subtype of sources. Instead of generating or capturing independent media, a transition source takes two inputs—the source being transitioned from (Source A) and the source being transitioned to (Source B)—and blends them over an active duration using graphics shaders and interpolation logic.

Step 1: Define the Internal State Structure

Create a structure to hold the transition state, configuration values, and any custom graphics resources (such as effect files or textures):

#include <obs-module.h>

struct custom_transition {
    obs_source_t *source;
    gs_effect_t *effect;
    gs_eparam_t *param_a;
    gs_eparam_t *param_b;
    gs_eparam_t *param_progress;
};

Step 2: Implement Lifecycle Callbacks

The transition requires callbacks for creation, destruction, and property definition.

Creation and Destruction

static const char *custom_transition_get_name(void *unused)
{
    UNUSED_PARAMETER(unused);
    return "Custom Blend Transition";
}

static void *custom_transition_create(obs_data_t *settings, obs_source_t *source)
{
    struct custom_transition *t = bzalloc(sizeof(struct custom_transition));
    t->source = source;

    // Load custom rendering shader/effect
    char *effect_path = obs_module_file("custom_transition.effect");
    obs_enter_graphics();
    t->effect = gs_effect_create_from_file(effect_path, NULL);
    if (t->effect) {
        t->param_a = gs_effect_get_param_by_name(t->effect, "tex_a");
        t->param_b = gs_effect_get_param_by_name(t->effect, "tex_b");
        t->param_progress = gs_effect_get_param_by_name(t->effect, "progress");
    }
    obs_leave_graphics();
    bfree(effect_path);

    obs_source_update(source, settings);
    return t;
}

static void custom_transition_destroy(void *data)
{
    struct custom_transition *t = data;

    obs_enter_graphics();
    if (t->effect) {
        gs_effect_destroy(t->effect);
    }
    obs_leave_graphics();

    bfree(t);
}

Step 3: Implement Video Rendering

The rendering callback is where the visual transition occurs. OBS provides transition helper functions to retrieve the transition progress (a float from 0.0f to 1.0f) and render the blended frames.

static void custom_transition_callback(void *data, gs_texture_t *a, gs_texture_t *b, float t, uint32_t cx, uint32_t cy)
{
    struct custom_transition *trans = data;

    if (!trans->effect)
        return;

    gs_effect_set_texture(trans->param_a, a);
    gs_effect_set_texture(trans->param_b, b);
    gs_effect_set_float(trans->param_progress, t);

    while (gs_effect_loop(trans->effect, "Draw")) {
        gs_draw_sprite(NULL, 0, cx, cy);
    }
}

static void custom_transition_video_render(void *data, gs_effect_t *effect)
{
    UNUSED_PARAMETER(effect);
    struct custom_transition *t = data;

    // obs_transition_video_render delegates texture binding and progress handling
    obs_transition_video_render(t->source, custom_transition_callback);
}

Step 4: Populate the obs_source_info Structure

Set up the obs_source_info definition, setting .type to OBS_SOURCE_TYPE_TRANSITION and adding the OBS_SOURCE_COMPOSITE and OBS_SOURCE_VIDEO output flags.

struct obs_source_info custom_transition_info = {
    .id             = "custom_transition",
    .type           = OBS_SOURCE_TYPE_TRANSITION,
    .output_flags   = OBS_SOURCE_VIDEO | OBS_SOURCE_COMPOSITE,
    .get_name       = custom_transition_get_name,
    .create         = custom_transition_create,
    .destroy        = custom_transition_destroy,
    .video_render   = custom_transition_video_render,
};

Step 5: Register the Source in obs_module_load

Expose the transition to the OBS Studio core within the plugin entry point:

OBS_DECLARE_MODULE()
OBS_MODULE_USE_DEFAULT_LOCALE("custom_transition", "en-US")

bool obs_module_load(void)
{
    obs_register_source(&custom_transition_info);
    return true;
}

Once registered, the transition type becomes immediately selectable in OBS Studio through the Scene Transitions dock and the transition properties dialog.
