OBS Studio LUT Color Clipping Thresholds Explained

OBS Studio manages color transforms by passing video frames through dedicated GPU pixel shaders, where Look-Up Table (LUT) application relies on strict mathematical clipping thresholds bounded between 0.0 and 1.0 in normalized floating-point space. When processing out-of-gamut or high-dynamic-range color data, any values that fall below 0.0 or exceed 1.0 are hard-clamped, preventing coordinate sampling errors outside the mapped dimensions of the LUT texture.

The Mathematical Bounds: 0.0 and 1.0

OBS Studio processes visual sources in a standardized normalized floating-point color pipeline. Under this model:

  • Lower Threshold (Black Point): 0.0 (corresponding to integer value 0 in 8-bit sRGB).
  • Upper Threshold (White Point): 1.0 (corresponding to integer value 255 in 8-bit sRGB).

When a source produces out-of-gamut data—such as negative color values resulting from color space conversions or values exceeding standard dynamic range (SDR) limits—the underlying HLSL shader enforces these limits using the saturate() function or hardware-level clamp() texture addressing modes.

How the LUT Shader Handles Out-of-Gamut Pixels

The standard LUT filter in OBS Studio reads an input pixel's red, green, and blue components to determine the coordinates needed to sample the LUT image (typically a flattened 2D representation of a 3D color cube, such as a 512×512 or 256×16 texture).

Before calculating the 2D UV texture coordinates, the shader clamps the RGB components:

\[\text{Clamped Color} = \min(\max(\text{Color}, 0.0), 1.0)\]

If an input color channel contains an out-of-gamut value such as \(-0.15\) or \(1.40\), it is truncated directly to \(0.0\) and \(1.0\), respectively.

Furthermore, the sampler state configured in the graphics pipeline employs the Clamp address mode:

  • AddressU = Clamp;
  • AddressV = Clamp;

This ensures that even if mathematical floating-point imprecision occurs at the borders of the LUT texture, the GPU fetches the outermost valid edge pixels rather than wrapping around or extrapolating beyond the texture boundary.

Consequences for Production Workflows

Because OBS Studio imposes a hard threshold at \([0.0, 1.0]\), wide-gamut (e.g., Rec. 2020) and high-dynamic-range (HDR) sources will experience immediate highlight clipping and shadow crushing if passed through standard 8-bit or standard SDR LUT filters without prior tone-mapping. Any color information residing outside standard SDR boundaries is discarded at the threshold stage rather than rolled off smoothly. Colorists targeting OBS Studio must ensure input footage is converted and tone-mapped to fit strictly within the normalized \(0.0\) to \(1.0\) range before the LUT filter is executed.
